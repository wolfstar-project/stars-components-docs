## Bug fixes

- **`@wolfstar/plugin-i18next` 2.0.4**. Fixed TypeScript overload resolution in `getSupportedLanguageT`, `getSupportedUserLanguageT`, and `fetchKey` when the `key` argument is a union type (for example, a ternary expression). The compiler no longer misreads an options object as a positional `defaultValue` string. Each call shape is now its own overload. The previous generic signature is kept as a deprecated trailing overload for full backward compatibility. See [`@wolfstar/plugin-i18next`](/documentation/packages/plugin-i18next).
