## Description

Very basic weather helper functions for several Star bots to ensure we do not duplicate code.

## Features

- Powered by the `@wolfstar/safe-fetch` package

## Usage

You can use the functions exported from this package to interact with the [Weather API](https://wttr.in).

```typescript
import { getWeatherData } from '@wolfstar/weather-helpers';

const result = await getWeatherData('Amsterdam', 'en-us');
console.log(result);
```
