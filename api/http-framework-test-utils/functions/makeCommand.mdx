Build a new command.

## makeCommand() function

```typescript
function makeCommand(options: CommandBuilder[]): APIApplicationCommand
function makeCommand(options: Map<string, CommandBuilder>): APIApplicationCommand
function makeCommand(options: CommandBuilder[] | Map<string, CommandBuilder>): APIApplicationCommand
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| options | CommandBuilder[] \| Map&lt;string, CommandBuilder&gt; | Options for creating the command |

## Returns

A [APIApplicationCommand](https://discord-api-types.dev/api/discord-api-types-v10/enum/ApplicationCommandType) (ChatInput)

## Type Aliases

| Type Alias | Value |
|-----------|-------|
| CommandBuilder | (builder: APIApplicationCommand) => APIApplicationCommand |

## Examples

:::info
The examples below are in TypeScript and demonstrate how to use `makeCommand`
with both a Map and an array.
:::

### With a Map

```typescript
import { ApplicationCommandType } from 'discord-api-types/v10';
import { makeCommand } from '@sapphire/http-framework-test-utils';

const map = new Map();

map.set('help', (builder) =>
  builder
    .setName('help')
    .setDescription('Get help with the bot')
    .setType(ApplicationCommandType.ChatInput)
);

const command = makeCommand(map);
```

### Without a Map

```typescript
import { ApplicationCommandType } from 'discord-api-types/v10';
import { makeCommand } from '@sapphire/http-framework-test-utils';

const command = makeCommand([
  (builder) =>
    builder
      .setName('help')
      .setDescription('Get help with the bot')
      .setType(ApplicationCommandType.ChatInput)
]);
```
