Utility to mock a Snowflake generator. Based on [cfworkers-snowkylin](https://github.com/futpib/snowflake-cfworker). This generates an incremental number in the Float64 range, and is ascending, but it is **not** a real Snowflake generator.

## createSnowflakeGenerator() function

```typescript
function createSnowflakeGenerator(): SnowflakeGenerator
```

## Returns

An ascending number stored in a [BigInt](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/BigInt) format, represented as a string.
