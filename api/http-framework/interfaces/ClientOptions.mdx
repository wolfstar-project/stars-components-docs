### hmr?

> `optional` **hmr?**: [`HMROptions`](HMROptions)

Defined in: [packages/http-framework/src/lib/Client.ts:304](https://github.com/wolfstar-project/stars-components/blob/5aefd164bc5fc41e5a35d3abf908c288163dd354/packages/http-framework/src/lib/Client.ts#L304)

The Hot Module Reloading options. When [HMROptions.enabled](HMROptions#enabled) is `true`, [Client#load](../classes/Client#load) starts a
[HotModuleReloader](../classes/HotModuleReloader) that watches every store path and reloads pieces as their files change.

#### Remarks

HMR is meant for development only, keep it disabled in production.

#### Default

```ts
undefined // HMR is not started
```

#### Since

3.3.0
