<Warning>
	**This package has been removed.** `@wolfstar/logger` is no longer published or maintained, and its source is no longer part of the
	stars-components repository. Use [`@wolfstar/plugin-logger`](/documentation/packages/plugin-logger) instead.
</Warning>

## Replacement

[`@wolfstar/plugin-logger`](/documentation/packages/plugin-logger) replaces the built-in console logger of
[`@wolfstar/http-framework`](/documentation/packages/http-framework) through the plugin lifecycle. It implements the same
`ILogger` contract, so code that writes through `container.logger` keeps working, and it adds support for multiple
transports.

Remove the old package and install the plugin:

```bash
pnpm remove @wolfstar/logger
pnpm add @wolfstar/plugin-logger
```

Import `LogLevel` from `@wolfstar/http-framework` instead of `@wolfstar/logger`:

```diff
-import { Logger, LogLevel } from '@wolfstar/logger';
+import { LogLevel } from '@wolfstar/http-framework';
```

`@wolfstar/logger` is deprecated in favor of [`@wolfstar/plugin-logger`](/documentation/packages/plugin-logger). The
plugin lives in the [`wolfstar-project/plugins`](https://github.com/wolfstar-project/plugins) repository alongside the
other `@wolfstar/plugin-*` packages. It offers pluggable transports (`consola`, `evlog`, `winston`, Sentry) and keeps the
`trace`/`debug`/`info`/`warn`/`error`/`fatal` methods you already use. See the
[plugin page](/documentation/packages/plugin-logger#migration-from-wolfstarlogger) for the code changes.
