---
title: Features
description: A cross-package tour of the features Stars Components ships, from HTTP-first Discord interactions and i18n to testing, logging, and platform helpers.
---

- [HTTP-first Discord interactions](/documentation/packages/http-framework) — signature verification, routing, and the
  application-command registry, with no gateway connection
- [Project scaffolding](/documentation/packages/create-http-framework) — `pnpm create @wolfstar/http-framework` generates the entry
  point, an example command, environment files, and your linter/formatter of choice
- [Typed commands and subcommands](/documentation/guide/commands) — decorators over regular classes, discovered by piece stores
- [Internationalization](/documentation/packages/plugin-i18next) — typed keys (`T` / `FT`, `resolveKey`), localized command builders,
  per-guild language resolution, and optional hot reload
- [Locale loading](/documentation/packages/i18next-backend) — loads and merges locale files across directories
- [Interaction testing](/documentation/packages/http-framework-test-utils) — typed fixtures, a local harness, and dedicated Vitest
  matchers, with no network server involved
- [Typed environment variables](/documentation/packages/env-utilities) — dotenv loading plus parsers that fail loudly on bad input
- [Result-based fetch](/documentation/packages/safe-fetch) — HTTP errors as values instead of thrown exceptions
- [Structured logging](/documentation/packages/logger) and [Influx metrics](/documentation/packages/influx-utilities)
- [Shared pieces](/documentation/packages/shared-http-pieces) — drop-in commands and listeners via a `/register` import
- [Platform helpers](/documentation/packages/reddit-helpers) for Reddit, [Twitch](/documentation/packages/twitch-helpers), and
  [weather](/documentation/packages/weather-helpers)
- [Generated API reference](/documentation/api) — built from every public entry point on each documentation build

Browse the full list on the [packages index](/documentation/packages), or read [Why Stars Components](/documentation/guide/why) for the
reasoning behind the split.
