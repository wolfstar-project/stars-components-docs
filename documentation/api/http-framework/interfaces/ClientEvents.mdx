### commandError

<ApiMember kind="property" signature={['commandError: [error: unknown, context: ', ['ClientEventCommandContext', '/documentation/api/http-framework/interfaces/ClientEventCommandContext'], ']']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/9d40129da57632753ba336f076c61dbe4a84131d/packages/http-framework/src/lib/ClientEvents.ts#L141', label: 'packages/http-framework/src/lib/ClientEvents.ts:141' }}>

Emitted when a command throws something that is not a [UserError](/documentation/api/http-framework/classes/UserError). A [UserError](/documentation/api/http-framework/classes/UserError) is emitted as
[ClientEvents.chatInputCommandDenied](/documentation/api/http-framework/interfaces/ClientEvents#chatinputcommanddenied) or [ClientEvents.contextMenuCommandDenied](/documentation/api/http-framework/interfaces/ClientEvents#contextmenucommanddenied) instead.

Since 6.3.0 a thrown [UserError](/documentation/api/http-framework/classes/UserError) (such as the `PreconditionError` of `@wolfstar/decorators`) no
longer reaches this event.

</ApiMember>

### pluginLoaded

<ApiMember kind="property" signature={['pluginLoaded: [hook: ', ['PluginHook', '/documentation/api/http-framework/enumerations/PluginHook'], ', name: string]']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/9d40129da57632753ba336f076c61dbe4a84131d/packages/http-framework/src/lib/ClientEvents.ts#L98', label: 'packages/http-framework/src/lib/ClientEvents.ts:98' }}>

Emitted after a plugin hook runs, providing the hook's [PluginHook](/documentation/api/http-framework/enumerations/PluginHook) and the plugin's name
(or `undefined` when the registering plugin did not provide one).

The `PreGenericsInitialization`, `PreInitialization`, and `PostInitialization` hooks run
synchronously inside the `Client` constructor, so their emissions fire before `new Client()`
returns. A listener attached afterwards cannot observe them (not even one added by a subclass,
whose constructor body only runs after `super()` has already executed those hooks), so only the
`PreLoad` (during `Client#load`) and `PostListen` (during `Client#listen`) emissions are
observable. To react to the constructor-phase hooks, use the plugin hooks themselves.

</ApiMember>
