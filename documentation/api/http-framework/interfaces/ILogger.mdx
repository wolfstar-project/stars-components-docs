The contract every logger must fulfill to be usable as `container.logger`.

The framework ships a minimal [Logger](../classes/Logger) that writes to the console, and expects richer implementations
(file transports, structured output, and alike) to be provided by a plugin through
[ClientLoggerOptions.instance](ClientLoggerOptions#instance).

## Since

3.4.0
