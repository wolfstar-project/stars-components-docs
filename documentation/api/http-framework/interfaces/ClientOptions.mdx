### hmr?

<ApiMember kind="property" badges={['optional', 'since 3.3.0']} signature={['hmr?: ', ['HMROptions', '/documentation/api/http-framework/interfaces/HMROptions']]} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/1e49b8a94be9af38a297e145cedcd8cf16678b3c/packages/http-framework/src/lib/Client.ts#L329', label: 'packages/http-framework/src/lib/Client.ts:329' }}>

The Hot Module Reloading options. When [HMROptions.enabled](/documentation/api/http-framework/interfaces/HMROptions#enabled) is `true`, [Client#load](/documentation/api/http-framework/classes/Client#load) starts a
[HotModuleReloader](/documentation/api/http-framework/classes/HotModuleReloader) that watches every store path and reloads pieces as their files change.

HMR is meant for development only, keep it disabled in production.

**Default**

```ts
undefined; // HMR is not started
```

</ApiMember>
