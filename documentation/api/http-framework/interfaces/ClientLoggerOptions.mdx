### instance?

> `optional` **instance?**: [`ILogger`](ILogger)

Defined in: [packages/http-framework/src/lib/Client.ts:331](https://github.com/wolfstar-project/stars-components/blob/5aefd164bc5fc41e5a35d3abf908c288163dd354/packages/http-framework/src/lib/Client.ts#L331)

The [ILogger](ILogger) to use instead of the built-in [Logger](../classes/Logger). Plugins set this from a
[PluginHook.PreGenericsInitialization](../enumerations/PluginHook#pregenericsinitialization) hook to extend the framework's logging.

#### Default

```ts
undefined // a new Logger is created
```

#### Since

3.4.0
