## Properties

### instance?

<ApiMember kind="property" badges={['optional', 'since 3.4.0']} signature={['instance?: ', ['ILogger', '/documentation/api/http-framework/interfaces/ILogger']]} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/a79b487575d2b897a128e5a1f27abd82d614a24e/packages/http-framework/src/lib/Client.ts#L392', label: 'packages/http-framework/src/lib/Client.ts:392' }}>

The [ILogger](/documentation/api/http-framework/interfaces/ILogger) to use instead of the built-in [Logger](/documentation/api/http-framework/classes/Logger). Plugins set this from a
[PluginHook.PreGenericsInitialization](/documentation/api/http-framework/enumerations/PluginHook#member-pregenericsinitialization) hook to extend the framework's logging.

**Default**

```ts
undefined; // a new Logger is created
```
