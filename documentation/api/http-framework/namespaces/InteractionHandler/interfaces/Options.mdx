### preconditions?

<ApiMember kind="property" badges={['optional', 'since 6.3.0']} signature={['preconditions?: ', ['PreconditionArrayResolvable', '/documentation/api/http-framework/type-aliases/PreconditionArrayResolvable'], '<', ['PreconditionFunction', '/documentation/api/http-framework/type-aliases/PreconditionFunction'], '<', ['MessageComponent', '/documentation/api/http-framework/namespaces/Interactions/type-aliases/MessageComponent'], ', ', ['InteractionHandler', '/documentation/api/http-framework/classes/InteractionHandler'], '<', ['Options', '/documentation/api/http-framework/namespaces/InteractionHandler/interfaces/Options'], '>>>']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/c2542d72639334a6f68ac733336ee9e95abf4d15/packages/http-framework/src/lib/structures/InteractionHandler.ts#L44', label: 'packages/http-framework/src/lib/structures/InteractionHandler.ts:44' }}>

The checks to run, in order, before the handler, after the global preconditions. An entry is the name of a
`Precondition` piece (which needs an `interactionHandlerRun` method to apply), that name with a `context`, a
function, or an array of entries (see `Command.Options.preconditions`). The first denial stops the interaction: the handler is not run and the error is
emitted as `interactionHandlerDenied`.

**Default**
