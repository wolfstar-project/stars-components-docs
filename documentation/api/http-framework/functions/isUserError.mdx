Checks whether a value is a [UserError](/documentation/api/http-framework/classes/UserError), which is how the client tells an expected failure from an unexpected
one.

`instanceof` is tried first. A bundle that inlines the framework, or a second installed copy of it, has its
own `UserError` class that `instanceof` does not recognise, so any `Error` with a string `identifier` and a `context`
property is accepted too.
