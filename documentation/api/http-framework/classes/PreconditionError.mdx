Errors thrown by preconditions, that is, any check that runs before a command or an interaction
handler is executed, such as the guild restrictions applied by
[RestrictGuildIds](/documentation/api/http-framework/functions/RestrictGuildIds).

<ApiSignature tokens={['class PreconditionError extends ', ['UserError', '/documentation/api/http-framework/classes/UserError']]} />

<ApiHierarchy extends={[[['UserError', '/documentation/api/http-framework/classes/UserError']]]} />

Being a [UserError](/documentation/api/http-framework/classes/UserError), it is emitted as a `*Denied` event when thrown from a command, an autocomplete
handler, or an interaction handler, and not as `commandError`. The framework has no precondition store: the
decorators of `@wolfstar/decorators` are what throws it.

**Example**

```typescript
throw new PreconditionError({
	precondition: 'GuildIds',
	identifier: Identifiers.PreconditionGuildIds,
	message: 'This command can only be used in specific guilds.',
	context: { guildIds: ['737141877803057244'] }
});
```
