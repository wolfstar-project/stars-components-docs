A per-command registry passed to [`Command.registerApplicationCommands`](/documentation/api/http-framework/classes/Command#registerapplicationcommands), allowing commands to be
registered imperatively, without relying on decorators.

This is the decorator-free equivalent of [RegisterCommand](/documentation/api/http-framework/functions/RegisterCommand), [RegisterSubcommand](/documentation/api/http-framework/functions/RegisterSubcommand),
[RegisterSubcommandGroup](/documentation/api/http-framework/functions/RegisterSubcommandGroup), [RegisterMessageCommand](/documentation/api/http-framework/functions/RegisterMessageCommand), [RegisterUserCommand](/documentation/api/http-framework/functions/RegisterUserCommand), and
[RestrictGuildIds](/documentation/api/http-framework/functions/RestrictGuildIds); both approaches can be used interchangeably as they share the same underlying
[`ApplicationCommandRegistryEntry`](/documentation/api/http-framework/namespaces/ApplicationCommandRegistryEntry).
