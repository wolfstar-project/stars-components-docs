Called when a command is unloaded.

This also drops the command's [ApplicationCommandRegistryEntry](/documentation/api/http-framework/namespaces/ApplicationCommandRegistryEntry) from the
[ApplicationCommandRegistry](/documentation/api/http-framework/namespaces/ApplicationCommandRegistry). The registry is keyed by command class, and reloading a command evaluates its
module again, producing a brand new class: without this, the entry of the previous class would linger and the
command would be pushed to Discord twice.
