A check that runs before a command method does, loaded from the `preconditions` directory into the
`preconditions` store.

A precondition with a `position` is global: it runs, in ascending order of `position`, before the
preconditions of every chat input and context menu command, and of every autocomplete and interaction handler that
it has a method for. Any other one runs only for the commands that list its
name in the `preconditions` option. The method it needs depends on the command, and a precondition that is asked to
run for a kind of command it has no method for denies the command with
[`Identifiers.PreconditionMissingChatInputHandler`](/documentation/api/http-framework/enumerations/Identifiers#member-preconditionmissingchatinputhandler) or
[`Identifiers.PreconditionMissingContextMenuHandler`](/documentation/api/http-framework/enumerations/Identifiers#member-preconditionmissingcontextmenuhandler).

**Example**

```typescript
import { Precondition } from '@wolfstar/http-framework';

export class UserPrecondition extends Precondition {
	public override chatInputRun(interaction: Precondition.ChatInputInteraction) {
		return interaction.user.id === process.env.OWNER_ID ? this.ok() : this.error({ message: 'Only the owner can use this command.' });
	}
}
```
