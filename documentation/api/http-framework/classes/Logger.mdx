The default [ILogger](/documentation/api/http-framework/interfaces/ILogger) implementation, writing every entry to the matching `console` method.

It is intentionally minimal: it only filters by [Logger.level](/documentation/api/http-framework/classes/Logger#level) and forwards the values as-is, leaving
timestamps, colours, and transports to a logger plugin that replaces `container.logger` through
[ClientLoggerOptions.instance](/documentation/api/http-framework/interfaces/ClientLoggerOptions#instance).
