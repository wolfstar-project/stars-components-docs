The base class for all plugins. Plugins hook into the [Client](/documentation/api/http-framework/classes/Client)'s lifecycle by defining static
methods keyed by the plugin symbols. Use [PluginManager.use](/documentation/api/http-framework/classes/PluginManager#use) (via `Client.use`) to register a plugin.
