The name of every event emitted by the [Client](../namespaces/Client), mirroring the keys of [ClientEvents](../interfaces/ClientEvents).

## Remarks

Each member's value is the plain event name, so they are interchangeable with the string literals
accepted by `Client#on`, `Client#emit`, and [Listener.Options.event](../namespaces/Listener/interfaces/Options#event).

## Example

```typescript
client.on(Events.CommandError, (error, context) => console.error(context.command.name, error));
```

3.4.0
