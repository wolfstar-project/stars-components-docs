The available log levels, ordered from the most verbose to the least. A [ILogger](/documentation/api/http-framework/interfaces/ILogger) only writes the entries
whose level is greater than or equal to its configured one, which makes [LogLevel.None](/documentation/api/http-framework/enumerations/LogLevel#member-none) a way to silence
every entry.
