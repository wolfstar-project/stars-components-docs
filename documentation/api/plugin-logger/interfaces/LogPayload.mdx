### message

<ApiMember kind="property" badges={['readonly']} signature={['readonly message: string']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/e92aba58265993929cc64df3a7c9948a05850e13/packages/plugin-logger/src/lib/types.ts#L30', label: 'packages/plugin-logger/src/lib/types.ts:30' }}>

The human-readable message: every value that is neither an `Error` nor a plain object, joined
by spaces. Falls back to the error's own message when nothing else was passed.

Derived from [LogPayload.values](/documentation/api/plugin-logger/interfaces/LogPayload#values) on first read, so transports share one interpretation of
what the caller meant instead of each guessing on their own.

</ApiMember>
