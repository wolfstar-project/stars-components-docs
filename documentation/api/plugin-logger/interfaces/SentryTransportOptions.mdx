## Properties

### breadcrumbLevel?

<ApiMember kind="property" badges={['optional']} signature={['breadcrumbLevel?: LogLevel']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-logger/src/lib/transports/SentryTransport.ts#L181', label: 'packages/plugin-logger/src/lib/transports/SentryTransport.ts:181' }}>

The lowest `LogLevel` recorded as a breadcrumb, for entries below [level](/documentation/api/plugin-logger/interfaces/SentryTransportOptions#level). Needs a
client exposing `addBreadcrumb`.

**Default**

```ts
undefined; // no breadcrumbs
```

</ApiMember>

### level?

<ApiMember kind="property" badges={['optional']} signature={['level?: LogLevel']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-logger/src/lib/transports/SentryTransport.ts#L173', label: 'packages/plugin-logger/src/lib/transports/SentryTransport.ts:173' }}>

### logLevel?

<ApiMember kind="property" badges={['optional']} signature={['logLevel?: LogLevel']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-logger/src/lib/transports/SentryTransport.ts#L189', label: 'packages/plugin-logger/src/lib/transports/SentryTransport.ts:189' }}>

The lowest `LogLevel` sent to Sentry Logs, regardless of [level](/documentation/api/plugin-logger/interfaces/SentryTransportOptions#level). Needs a client
exposing `logger`, and Sentry initialised with `enableLogs: true`.

**Default**

```ts
undefined; // no Sentry Logs
```

</ApiMember>
