A sink a [Logger](/documentation/api/plugin-logger/classes/Logger) writes entries to.

Transports are the extension point that replaces forking the package: implement this interface to
add a custom sink, and pass the instance through `ClientLoggerOptions.transports`.

### level?

<ApiMember kind="property" badges={['readonly', 'optional']} signature={['readonly level?: LogLevel']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-logger/src/lib/types.ts#L56', label: 'packages/plugin-logger/src/lib/types.ts:56' }}>

The lowest `LogLevel` this transport accepts. Entries below it are dropped before
[Transport.log](/documentation/api/plugin-logger/interfaces/Transport#log) is called, independently from the logger's own level.

**Default**

```ts
undefined; // the logger's level applies
```

A rejected promise or a thrown error is caught by the logger and reported to `console.error`,
