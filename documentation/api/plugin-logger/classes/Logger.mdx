The `ILogger` implementation this plugin installs as `container.logger`.

Unlike the framework's built-in `Logger`, which is hardcoded to `console`, this one fans every
entry out to a list of [transports](/documentation/api/plugin-logger/interfaces/Transport). Each transport filters by its own
[Transport.level](/documentation/api/plugin-logger/interfaces/Transport#level) on top of the logger's, so a Sentry sink can take only `error` and above
while the console keeps everything.
