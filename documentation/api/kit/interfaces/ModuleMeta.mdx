### compatibility?

<ApiMember kind="property" badges={['optional']} signature={['compatibility?: {\n  framework?: string;\n  stars?: string;\n}']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/3785ac54e2c681b0525fad9f298b406992acafd5/packages/kit/src/types.ts#L20', label: 'packages/kit/src/types.ts:20' }}>

### configKey?

<ApiMember kind="property" badges={['optional']} signature={['configKey?: string']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/3785ac54e2c681b0525fad9f298b406992acafd5/packages/kit/src/types.ts#L18', label: 'packages/kit/src/types.ts:18' }}>

A top-level `stars.config` key the module owns: what is written under it is merged over `defaults`, and the options
given inline (`[name, options]`, or `ctx.installModule`) over that. It must be a plain object, unique among the
installed modules and not a built-in key (`build`, `dev`, `modules`, …). To type it in `defineConfig`, augment
`StarsConfig`: `declare module '@wolfstar/schema' { interface StarsConfig { scheduledTasks?: Options } }`.

</ApiMember>

<ApiMember kind="property" signature={['name: string']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/3785ac54e2c681b0525fad9f298b406992acafd5/packages/kit/src/types.ts#L10', label: 'packages/kit/src/types.ts:10' }}>

</ApiMember>
