Ready-made [GatewayClientOptions.sweepers](/documentation/api/plugin-gateway/interfaces/GatewayClientOptions#sweepers), for a bot that only needs recent messages and threads: every hour,
messages untouched for 30 minutes are evicted, and so are threads archived for more than four hours.

<ApiSignature tokens={['const DefaultSweeperSettings: ', ['SweeperOptions', '/documentation/api/plugin-gateway/type-aliases/SweeperOptions']]} />

Unlike discord.js's `Options.DefaultSweeperSettings`, which is empty, it sweeps. Spread it to override an entity:
`sweepers: { ...DefaultSweeperSettings, users: { interval: 3_600, filter: () => (user) => user.bot } }`.
