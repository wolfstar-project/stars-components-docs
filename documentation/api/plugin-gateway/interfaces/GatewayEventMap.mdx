The events a [GatewayClient](/documentation/api/plugin-gateway/classes/GatewayClient) emits on top of the base `Client`'s ones, and their arguments.

<ApiSignature tokens={['interface GatewayEventMap']} />

Update events receive the previous state of the entity as read from the cache before the dispatch was applied, or
`null` when it was not cached. Delete events receive the cached entity (or `null`) alongside the raw dispatch data,
which always identifies the deleted entity.

With the matching `Partials` enabled, uncached messages, users, members, thread members, scheduled events,
soundboard sounds, polls, and direct messages are partial structures (`partial` is `true`) instead of `null`.

### dispatch

<ApiMember kind="property" signature={['dispatch: [payload: ', ['GatewayDispatchPayload', 'https://discord-api-types.dev/api/discord-api-types-v10#GatewayDispatchPayload'], ', shardId: number, state: unknown]']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/5bb3b6c632bbc7d73534213f6634e9fd02ee1c15/packages/plugin-gateway/src/util/events.ts#L129', label: 'packages/plugin-gateway/src/util/events.ts:129' }}>

Emitted for every gateway dispatch once it has been written to the cache (right away without one), before the
matching event, with the raw payload. Unlike `raw`, a listener reading the cache sees the dispatch applied, which
is what forwarding it to other processes sharing the cache needs.

Not emitted for `INTERACTION_CREATE`, served by the HTTP endpoint, nor for a dispatch dropped because its cache
write failed with [GatewayClientOptions.cacheFailure](/documentation/api/plugin-gateway/interfaces/GatewayClientOptions#cachefailure) set to `"skip"`.

Also emitted, with `s: 0` and no `raw` before it, for the `GUILD_DELETE` the client makes up for a cached guild a
`READY` no longer lists, see [GatewayClient.reconcileGuilds](/documentation/api/plugin-gateway/classes/GatewayClient#reconcileguilds).

`state` is what the dispatch's handler read before the cache write, e.g. the cached message a `MESSAGE_UPDATE`
replaces, or `undefined`. It is what [GatewayClient.serializeDispatchState](/documentation/api/plugin-gateway/classes/GatewayClient#serializedispatchstate) serializes for other processes.

</ApiMember>
