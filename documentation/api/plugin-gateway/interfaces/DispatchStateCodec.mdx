Carries the previous state a dispatch handler reads before the cache write (`DispatchHandler#before`) across
processes: [DispatchStateCodec.serialize](/documentation/api/plugin-gateway/interfaces/DispatchStateCodec#serialize) turns it into plain, codec-safe data on the gateway process, and
[DispatchStateCodec.revive](/documentation/api/plugin-gateway/interfaces/DispatchStateCodec#revive) builds the structures again on a worker.
