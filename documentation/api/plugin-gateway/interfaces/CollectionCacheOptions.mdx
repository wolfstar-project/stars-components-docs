### keepOverLimit?

<ApiMember kind="property" badges={['optional']} signature={['keepOverLimit?: (value: Value, key: string, cache: ', ['Map', 'https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map'], '<string, Value>) => boolean']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/e92aba58265993929cc64df3a7c9948a05850e13/packages/plugin-gateway/src/util/CollectionCache.ts#L32', label: 'packages/plugin-gateway/src/util/CollectionCache.ts:32' }}>

Decides which entries `maxSize` never evicts: the oldest one it answers `false` for is evicted instead. When it
answers `true` for every entry, the cache grows past `maxSize`.

</ApiMember>

### maxSize?

<ApiMember kind="property" badges={['optional']} signature={['maxSize?: number']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/e92aba58265993929cc64df3a7c9948a05850e13/packages/plugin-gateway/src/util/CollectionCache.ts#L27', label: 'packages/plugin-gateway/src/util/CollectionCache.ts:27' }}>

The maximum amount of entries, the oldest one being evicted when a new one would exceed it. `0` holds nothing:
`add` still builds the structure, without keeping it.

**Default**

```ts
Infinity;
```

</ApiMember>

### refresh?

<ApiMember kind="property" badges={['optional']} signature={['refresh?: (value: Value) => Value']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/e92aba58265993929cc64df3a7c9948a05850e13/packages/plugin-gateway/src/util/CollectionCache.ts#L20', label: 'packages/plugin-gateway/src/util/CollectionCache.ts:20' }}>

Called with an instance every time it is read with `get` or updated with `add`, to bring what it holds besides
its data (its relations) up to date. It returns the instance to hand out.

</ApiMember>
