A message built from its IDs alone, like discord.js's `PartialMessage`: `partial` is `true`, and `content`, `author`
and `cleanContent` may be missing. Narrow a `Message | PartialMessage` with `partial`; [Message.fetch](/documentation/api/plugin-gateway/classes/Message#fetch)
completes it.
