### resumable?

<ApiMember kind="property" badges={['optional']} signature={['resumable?: boolean']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/5bb3b6c632bbc7d73534213f6634e9fd02ee1c15/packages/plugin-gateway/src/GatewayClient.ts#L325', label: 'packages/plugin-gateway/src/GatewayClient.ts:325' }}>

Whether to keep the shards' sessions resumable, for the next process to resume them (e.g. during a deploy): the
shards close with a code Discord does not invalidate the session on, and their sessions stay stored. Only
meaningful with [GatewayClientOptions.sessionStore](/documentation/api/plugin-gateway/interfaces/GatewayClientOptions#sessionstore), or with `gateway.updateSessionInfo`.

**Default**

```ts
false;
```
