Manages the channels of one [CategoryChannel](/documentation/api/plugin-gateway/classes/CategoryChannel), like discord.js's `CategoryChannelChildManager`.

<ApiSignature tokens={['class CategoryChannelChildManager extends ', ['BaseManager', '/documentation/api/plugin-gateway/classes/BaseManager']]} />

<ApiHierarchy extends={[[['BaseManager', '/documentation/api/plugin-gateway/classes/BaseManager']]]} />

It holds no cache of its own: [CategoryChannelChildManager.cache](/documentation/api/plugin-gateway/classes/CategoryChannelChildManager#cache) is read from the channel cache each time, so
it always agrees with `client.channels`. With a remote cache the store must be able to enumerate its entries, or
reading it throws `CacheNotIterable`, like `listCached`.
