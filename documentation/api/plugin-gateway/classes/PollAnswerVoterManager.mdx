Manages the voters of one [PollAnswer](/documentation/api/plugin-gateway/classes/PollAnswer), like discord.js's `PollAnswerVoterManager`.

<ApiSignature tokens={['class PollAnswerVoterManager extends ', ['BaseManager', '/documentation/api/plugin-gateway/classes/BaseManager']]} />

<ApiHierarchy extends={[[['BaseManager', '/documentation/api/plugin-gateway/classes/BaseManager']]]} />

Unlike discord.js's, it has no `cache`: the voters of an answer are not tracked, so [PollAnswerVoterManager.fetch](/documentation/api/plugin-gateway/classes/PollAnswerVoterManager#fetch)
reads them from the API each time (and caches the users).
