The raw API data the structure wraps.

<ApiParam name="Relations" type={['extends object']} defaultValue="object">

The relations of the structure, resolved from the cache by its manager.

</ApiParam>

</ApiParams>

It is mixed into [Structure](/documentation/api/plugin-gateway/classes/Structure) and into every class extending one of `@discordjs/structures`' structures, which
also have to call [initStructure](/documentation/api/plugin-gateway/functions/initStructure) from their constructor:

```typescript
export interface User extends StructureMixin<APIUser> {}
export class User extends BaseUser {
	public constructor(data: Partial<APIUser>, relations: object = {}) {
		super(data);
		initStructure(this, data, relations);
	}
}
Mixin(User, [StructureMixin]);
```

The client that instantiated this structure, like discord.js's `Base#client`: the one whose manager built it, or
the most recently constructed [GatewayClient](/documentation/api/plugin-gateway/classes/GatewayClient) for structures built by hand from a raw payload.

It is not part of the structure's data, so it is neither serialized by `toJSON` nor stored in the cache.

</ApiMember>
