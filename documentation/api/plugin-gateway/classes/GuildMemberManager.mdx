Manages the [GuildMember](/documentation/api/plugin-gateway/classes/GuildMember)s known to the client.

`guild.members` (or `client.guilds.members(guildId)`) is this manager built for one guild, like discord.js's:
`cache` takes the user's ID alone, and the methods lose their `guildId` argument.

### cache

<ApiMember kind="property" badges={['readonly']} signature={['readonly cache: ', ['Cache', '/documentation/api/plugin-gateway/interfaces/Cache'], '<', ['GuildMember', '/documentation/api/plugin-gateway/classes/GuildMember'], '>']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/5bb3b6c632bbc7d73534213f6634e9fd02ee1c15/packages/plugin-gateway/src/managers/CachedManager.ts#L142', label: 'packages/plugin-gateway/src/managers/CachedManager.ts:142' }} inheritedFrom={[['CachedManager.cache', '/documentation/api/plugin-gateway/classes/CachedManager#cache']]}>

The cache of this manager's entity.

On a manager built for one guild (`guild.members`), it is the client's cache taking the ID of the entity alone.
`get`, `has`, `set` and `delete` cost the same as on the client's; `getSize` and `clear` scan the keys of every
guild to find the ones of this guild, unlike discord.js's per-guild collections: avoid calling them for every
guild in a loop.

**Example**

```typescript
const user = await client.users.cache.get(userId);
```

</ApiMember>

### me

<ApiMember kind="property" badges={['readonly']} signature={['readonly me: InGuild extends true ? ', ['GuildMember', '/documentation/api/plugin-gateway/classes/GuildMember'], ' | null : (guildId: string) => ', ['Awaitable', '/documentation/api/plugin-cache/type-aliases/Awaitable'], '<', ['GuildMember', '/documentation/api/plugin-gateway/classes/GuildMember'], ' | null>']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/5bb3b6c632bbc7d73534213f6634e9fd02ee1c15/packages/plugin-gateway/src/managers/GuildMemberManager.ts#L319', label: 'packages/plugin-gateway/src/managers/GuildMemberManager.ts:319' }}>

The bot's own member in a guild, from the cache: `null` when it is not cached. Use
[GuildMemberManager.fetchMe](/documentation/api/plugin-gateway/classes/GuildMemberManager#fetchme) to fall back to the API.

On the manager of a guild it is a getter, like discord.js's `guild.members.me`: the member itself, or a promise
of it with an asynchronous cache (see `GatewayCacheConfig`). On `client.members` it is a function taking the
guild's ID, synchronous when the member cache is.

</ApiMember>
