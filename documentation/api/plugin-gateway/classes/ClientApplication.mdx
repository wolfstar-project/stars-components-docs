The application of the bot, the entry point for everything owned by the application rather than by a guild, like
discord.js's `ClientApplication`.

<ApiSignature tokens={['class ClientApplication extends ', ['Application', '/documentation/api/plugin-gateway/classes/Application']]} />

<ApiHierarchy extends={[[['Application', '/documentation/api/plugin-gateway/classes/Application']]]} />

Unlike discord.js, `client.application` exists from the construction of the client, with only its ID known until
`READY` patches in the flags, and [ClientApplication.fetch](/documentation/api/plugin-gateway/classes/ClientApplication#fetch) the rest: check [ClientApplication.partial](/documentation/api/plugin-gateway/classes/ClientApplication#partial)
before relying on the other fields.
