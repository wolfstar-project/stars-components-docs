### cache

<ApiMember kind="property" badges={['readonly']} signature={['readonly cache: ', ['Cache', '/documentation/api/plugin-gateway/interfaces/Cache'], '<', ['GuildEmoji', '/documentation/api/plugin-gateway/classes/GuildEmoji'], '>']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-gateway/src/managers/CachedManager.ts#L142', label: 'packages/plugin-gateway/src/managers/CachedManager.ts:142' }} inheritedFrom={[['CachedManager.cache', '/documentation/api/plugin-gateway/classes/CachedManager#cache']]}>

The cache of this manager's entity.

On a manager built for one guild (`guild.members`), it is the client's cache taking the ID of the entity alone.
`get`, `has`, `set` and `delete` cost the same as on the client's; `getSize` and `clear` scan the keys of every
guild to find the ones of this guild, unlike discord.js's per-guild collections: avoid calling them for every
guild in a loop.

**Example**

```typescript
const user = await client.users.cache.get(userId);
```

</ApiMember>
