Structures can be built from any raw payload, be it a gateway dispatch, a cache hit, or a REST response. Their
[client](/documentation/api/plugin-gateway/classes/StructureMixin#client) is the one whose manager built them, the most recently constructed one
otherwise.

### client

<ApiMember kind="accessor" signature={['get client(): ', ['GatewayClient', '/documentation/api/plugin-gateway/classes/GatewayClient']]} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-gateway/src/structures/Structure.ts#L108', label: 'packages/plugin-gateway/src/structures/Structure.ts:108' }} inheritedFrom={[['StructureMixin.client', '/documentation/api/plugin-gateway/classes/StructureMixin#client']]}>

The client that instantiated this structure, like discord.js's `Base#client`: the one whose manager built it, or
the most recently constructed [GatewayClient](/documentation/api/plugin-gateway/classes/GatewayClient) for structures built by hand from a raw payload.

It is not part of the structure's data, so it is neither serialized by `toJSON` nor stored in the cache.

</ApiMember>
