The users, roles, and channels a message mentions.

<ApiSignature tokens={['class MessageMentions<InGuild extends boolean = boolean>']} />

<ApiParams title="Type Parameters">

<ApiParam name="InGuild" type={['extends boolean']} defaultValue="boolean" />

Users and members come with the message payload, and are replaced by their cached copies when the message was built
by `client.messages`, which also resolves the mentioned roles and channels from the cache, like discord.js.

### parsedUsers

<ApiMember kind="accessor" signature={['get parsedUsers(): ', ['Map', 'https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map'], '<string, ', ['User', '/documentation/api/plugin-gateway/classes/User'], '>']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-gateway/src/structures/messages/MessageMentions.ts#L137', label: 'packages/plugin-gateway/src/structures/messages/MessageMentions.ts:137' }}>

The users the content mentions, by ID, like discord.js's `MessageMentions#parsedUsers`, which also counts the
users the message does not ping.

Like discord.js, it reads the cache: a user the content mentions without the payload listing it is skipped when
it is not cached. The users the payload does list are included even when uncached, as discord.js adds them to its
cache first; here nothing is written to it.

</ApiMember>
