Creates a thread in the channel, or a post in a forum or media channel (with `message`). discord.js splits this in
`GuildTextThreadManager` and `GuildForumThreadManager`; here the manager is shared and the options are checked
against the type of the channel.

<ApiParams title="Parameters">

<ApiParam name="options" type={[['ThreadCreateOptions', '/documentation/api/plugin-gateway/type-aliases/ThreadCreateOptions']]}>

The thread's name and settings.

</ApiParam>

</ApiParams>

		'<',
		['AnyThreadChannel', '/documentation/api/plugin-gateway/type-aliases/AnyThreadChannel'],
		'>'
	]}
/>

</ApiParams>

<ApiParams title="Throws">

<ApiParam>

[GatewayTypeError](/documentation/api/plugin-gateway/classes/GatewayTypeError) `ThreadPostMessageRequired` in a forum or media channel without `message`,
`ThreadOptionsThreadOnly` there with `type` or `invitable`, and `ThreadOptionsPostOnly` with `message` or
`appliedTags` in any other channel.

</ApiParam>
