### maximumBodyLength?

<ApiMember kind="property" badges={['optional']} signature={['maximumBodyLength?: number']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-api/src/lib/structures/http/Server.ts#L90', label: 'packages/plugin-api/src/lib/structures/http/Server.ts:90' }}>

The maximum request body size in bytes, enforced by the built-in `body` middleware. A route can
lower or raise it with `RouteOptions.maximumBodyLength`.

```ts

```

</ApiMember>
