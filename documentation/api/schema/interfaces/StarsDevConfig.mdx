### url?

<ApiMember kind="property" badges={['optional']} signature={['url?: string']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/1871d36faec909343bbf824306a553a3eb1eb581/packages/schema/src/types/config.ts#L302', label: 'packages/schema/src/types/config.ts:302' }}>

The URL the bot listens on, shown in the dev UI's status line and used for [StarsDevConfig.health](/documentation/api/schema/interfaces/StarsDevConfig#health).

Resolved automatically, the way Vite's and Nuxt's dev servers do, from (in order) `dev.env.HTTP_PORT`, the
process's `HTTP_PORT`, the project's `src/.env*`/`.env*` (`HTTP_PORT` or `PORT`), or `3000`. `stars dev` also
resolves whether `localhost` should be shown as `127.0.0.1` instead, the same DNS-order check Vite does, so the
printed URL is always the one that is actually reachable.

**Default:** `http://localhost:3000` (or whichever port is found)

</ApiMember>
