## Properties

### dirs?

<ApiMember kind="property" badges={['optional']} signature={['dirs?: string[]']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/1871d36faec909343bbf824306a553a3eb1eb581/packages/schema/src/types/config.ts#L385', label: 'packages/schema/src/types/config.ts:385' }}>

Directories, relative to [StarsConfig.root](/documentation/api/schema/interfaces/StarsConfig#root), whose exported values are auto-importable. Entries are glob
path patterns: `'src/lib'` scans only the files directly inside it, `'src/lib/**'` scans recursively.

**Default**

```ts
['src/lib/**', 'src/utils/**'];
```

</ApiMember>

### dts?

<ApiMember kind="property" badges={['optional']} signature={['dts?: string']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/1871d36faec909343bbf824306a553a3eb1eb581/packages/schema/src/types/config.ts#L401', label: 'packages/schema/src/types/config.ts:401' }}>

The generated declaration file that types the auto imports, relative to [StarsConfig.root](/documentation/api/schema/interfaces/StarsConfig#root).
Include it in the project's tsconfig and add its directory to .gitignore.

**Default**

```ts
'.stars/imports.d.ts';
```

</ApiMember>

### enabled?

<ApiMember kind="property" badges={['optional']} signature={['enabled?: boolean']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/1871d36faec909343bbf824306a553a3eb1eb581/packages/schema/src/types/config.ts#L379', label: 'packages/schema/src/types/config.ts:379' }}>

Whether auto imports are enabled. Requires the `tsdown` build tool: the imports are injected at build time by
the `autoImports()` plugin from `@wolfstar/http-framework/auto-imports`, which the other tools cannot run.

**Default**

```ts
true when the build tool is 'tsdown', false otherwise
```

</ApiMember>
