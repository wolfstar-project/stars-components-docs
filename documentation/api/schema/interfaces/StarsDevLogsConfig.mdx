## Properties

### channels?

<ApiMember kind="property" badges={['optional']} signature={['channels?: string[]']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/c2542d72639334a6f68ac733336ee9e95abf4d15/packages/schema/src/types/config.ts#L199', label: 'packages/schema/src/types/config.ts:199' }}>

The channels shown when `stars dev` starts (`cli`, `build`, `bot`, `types`, `tunnel`, `hmr`, `commands`,
`interactions`, `http`, `lifecycle`, or one a plugin logs on). Every other channel starts hidden; the dev UI can
still toggle each of them, and the log file always receives everything.

**Default**

```ts
every channel
```

</ApiMember>

### dir?

<ApiMember kind="property" badges={['optional']} signature={['dir?: string | false']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/c2542d72639334a6f68ac733336ee9e95abf4d15/packages/schema/src/types/config.ts#L210', label: 'packages/schema/src/types/config.ts:210' }}>

A directory, relative to [StarsConfig.root](/documentation/api/schema/interfaces/StarsConfig#root), that receives one log file per `stars dev` run
(`dev-<timestamp>.log`), next to [StarsDevConfig.logFile](/documentation/api/schema/interfaces/StarsDevConfig#logfile) which only keeps the latest run.

**Default**

```ts
false;
```

</ApiMember>

### keep?

<ApiMember kind="property" badges={['optional']} signature={['keep?: number']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/c2542d72639334a6f68ac733336ee9e95abf4d15/packages/schema/src/types/config.ts#L216', label: 'packages/schema/src/types/config.ts:216' }}>

How many per-run files [StarsDevLogsConfig.dir](/documentation/api/schema/interfaces/StarsDevLogsConfig#dir) keeps, the file of the current run included; older ones
are deleted when a run starts. A positive integer: `1` keeps only the current run.

**Default**

```ts
10;
```

</ApiMember>
