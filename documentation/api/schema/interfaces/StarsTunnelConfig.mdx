## Properties

### domain?

<ApiMember kind="property" badges={['optional']} signature={['domain?: string']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/c2542d72639334a6f68ac733336ee9e95abf4d15/packages/schema/src/types/config.ts#L173', label: 'packages/schema/src/types/config.ts:173' }}>

A domain reserved in your ngrok account (for example `bot.ngrok.app`), so the tunnel keeps one hostname across runs.
Only for the `ngrok` provider.

</ApiMember>

### path?

<ApiMember kind="property" badges={['optional']} signature={['path?: string']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/c2542d72639334a6f68ac733336ee9e95abf4d15/packages/schema/src/types/config.ts#L186', label: 'packages/schema/src/types/config.ts:186' }}>

The path the interactions endpoint is served on, appended to the tunnel URL.

**Default**

```ts
'/';
```

</ApiMember>

### provider?

<ApiMember kind="property" badges={['optional']} signature={['provider?: ', ['StarsTunnelProvider', '/documentation/api/schema/type-aliases/StarsTunnelProvider']]} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/c2542d72639334a6f68ac733336ee9e95abf4d15/packages/schema/src/types/config.ts#L168', label: 'packages/schema/src/types/config.ts:168' }}>

The service that opens the tunnel. `cloudflared` needs no account (its hostname changes on every run); `ngrok` needs
an authtoken (`NGROK_AUTHTOKEN` in the environment or the project's `.env`) and the `@ngrok/ngrok` package installed
in the project.

**Default**

```ts
'cloudflared';
```

</ApiMember>

### updateEndpoint?

<ApiMember kind="property" badges={['optional']} signature={['updateEndpoint?: boolean']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/c2542d72639334a6f68ac733336ee9e95abf4d15/packages/schema/src/types/config.ts#L181', label: 'packages/schema/src/types/config.ts:181' }}>

Writes the tunnel's URL to the Discord application's `interactions_endpoint_url` when it changes.

This edits a live Discord application, so it is opt-in: it needs `DISCORD_TOKEN` and `DISCORD_APPLICATION_ID`
(or `APPLICATION_ID`) in the environment or the project's `.env`.

**Default**

```ts
false;
```

</ApiMember>

### url?

<ApiMember kind="property" badges={['optional']} signature={['url?: string']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/c2542d72639334a6f68ac733336ee9e95abf4d15/packages/schema/src/types/config.ts#L161', label: 'packages/schema/src/types/config.ts:161' }}>

An https URL you already serve; when unset a quick tunnel is opened instead (see [StarsTunnelConfig.provider](/documentation/api/schema/interfaces/StarsTunnelConfig#provider)).
Cannot be combined with `provider` or `domain`: a URL you already serve has no provider.

</ApiMember>
