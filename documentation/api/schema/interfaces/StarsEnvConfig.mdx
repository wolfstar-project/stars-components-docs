The environment `stars` registers in the built entry before any other module runs, the way a hand-written
`setup()` from `@wolfstar/env-utilities` would. On by default from `future.compatibilityVersion: 5` when the project
depends on `@wolfstar/env-utilities`, except with `experimental.enableNitro`.

### loader?

<ApiMember kind="property" badges={['optional']} signature={['loader?: "varlock" | "node" | "dotenv"']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/9ea8480804549ebe025c60ed2200d5edb0076243/packages/schema/src/types/config.ts#L511', label: 'packages/schema/src/types/config.ts:511' }} inheritedFrom={[['StarsEnvSetupOptions.loader', '/documentation/api/schema/interfaces/StarsEnvSetupOptions#loader']]}>

**Experimental.** `'node'` parses the files with Node.js' own `util.parseEnv`, `'dotenv'` with `dotenv` and
`dotenv-expand` (optional packages of `@wolfstar/env-utilities`), and `'varlock'` resolves the environment through
[varlock](https://varlock.dev). When left out, `'varlock'` is used for a project with a `.env.schema`, otherwise
`'dotenv'` if it is installed and `'node'` if it is not.

</ApiMember>

### path?

<ApiMember kind="property" badges={['optional']} signature={['path?: string']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/9ea8480804549ebe025c60ed2200d5edb0076243/packages/schema/src/types/config.ts#L500', label: 'packages/schema/src/types/config.ts:500' }} inheritedFrom={[['StarsEnvSetupOptions.path', '/documentation/api/schema/interfaces/StarsEnvSetupOptions#path']]}>

A custom `.env` path. Kept relative: `@wolfstar/env-utilities` resolves it against the bot's working directory

**Default:** `src/.env*`, then `.env*`

</ApiMember>
