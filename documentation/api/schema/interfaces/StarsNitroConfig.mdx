The [Nitro preset](https://nitro.build/deploy) `stars build` targets, only reachable once
`StarsExperimentalConfig.enableNitro` (itself gated on `StarsExperimentalConfig.enableVite`) is `true`
— see [StarsExperimentalConfig](/documentation/api/schema/type-aliases/StarsExperimentalConfig).
