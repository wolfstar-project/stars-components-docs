### hooks?

<ApiMember kind="property" badges={['optional']} signature={['hooks?: ', ['StarsHooksConfig', '/documentation/api/schema/type-aliases/StarsHooksConfig']]} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/3785ac54e2c681b0525fad9f298b406992acafd5/packages/schema/src/types/config.ts#L562', label: 'packages/schema/src/types/config.ts:562' }}>

### imports?

<ApiMember kind="property" badges={['optional']} signature={['imports?: boolean | ', ['StarsImportsConfig', '/documentation/api/schema/interfaces/StarsImportsConfig']]} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/3785ac54e2c681b0525fad9f298b406992acafd5/packages/schema/src/types/config.ts#L552', label: 'packages/schema/src/types/config.ts:552' }}>

Nuxt-style auto imports of the framework's exports and the project's own modules.
`false` disables them, `true` forces them on (requires the `tsdown` build tool). On by default with
`future.compatibilityVersion` 4 and later.

</ApiMember>

### modules?

<ApiMember kind="property" badges={['optional']} signature={['modules?: readonly (false | ', ['StarsModuleEntry', '/documentation/api/schema/type-aliases/StarsModuleEntry'], ' | null | undefined)[]']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/3785ac54e2c681b0525fad9f298b406992acafd5/packages/schema/src/types/config.ts#L569', label: 'packages/schema/src/types/config.ts:569' }}>

Installable modules (see `defineModule` in `@wolfstar/kit`), each a package name or a `[name, options]` tuple.
A package listed here is installed because the project says so, not because of its name: it is no longer
activated through the `@wolfstar/plugin-*` `/register` import the CLI otherwise injects. Falsy entries are
dropped.

</ApiMember>
