Reads a Redis stream through a consumer group, dispatching each entry to the [BrokerListener](/documentation/api/plugin-broker/namespaces/BrokerListener) pieces
registered for its event, and only acknowledging it once every one of them has resolved.

<ApiSignature tokens={['class BrokerConsumer implements Emitter']} />

<ApiHierarchy implements={[['Emitter']]} />

Implements the framework's `Listener.Emitter` contract itself, so `BrokerListener` pieces can bind to a
`BrokerConsumer` instance the same way `EventGatewayListener` pieces bind to a `GatewayClient`.

A listener that throws leaves its entry pending: it is redelivered the next time a consumer of the same
[name](/documentation/api/plugin-broker/interfaces/BrokerConsumerOptions#consumer) starts, or claimed once idle for [BrokerConsumerOptions.claimIdle](/documentation/api/plugin-broker/interfaces/BrokerConsumerOptions#claimidle),
until it exceeds [BrokerConsumerOptions.maxDeliveries](/documentation/api/plugin-broker/interfaces/BrokerConsumerOptions#maxdeliveries) and is moved to the dead-letter stream. Entries are
handled one at a time, so `stop()` only has to await the current one before returning.

Ensures the consumer group exists, then starts reading: first this consumer's own pending entries (redelivery
after a crash under the same name), then new ones, claiming idle entries along the way if
[BrokerConsumerOptions.claimIdle](/documentation/api/plugin-broker/interfaces/BrokerConsumerOptions#claimidle) is set, until [BrokerConsumer.stop](/documentation/api/plugin-broker/classes/BrokerConsumer#stop).

### stop()

<ApiMember kind="method" source={{ url: 'https://github.com/wolfstar-project/plugins/blob/5bb3b6c632bbc7d73534213f6634e9fd02ee1c15/packages/plugin-broker/src/BrokerConsumer.ts#L230', label: 'packages/plugin-broker/src/BrokerConsumer.ts:230' }}>

<ApiSignature
	tokens={['stop(): ', ['Promise', 'https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise'], '<void>']}
/>

Stops reading and awaits the in-flight entry, so it does not return until the current entry's listeners have
settled. Any entry left pending is redelivered the next time a consumer of the same name starts, or claimed by
another one once idle for [BrokerConsumerOptions.claimIdle](/documentation/api/plugin-broker/interfaces/BrokerConsumerOptions#claimidle).
