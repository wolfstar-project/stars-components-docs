### markDispatchesForwarded()

<ApiMember kind="method" badges={['optional']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-broker/src/lib/gateway.ts#L45', label: 'packages/plugin-broker/src/lib/gateway.ts:45' }}>

<ApiSignature tokens={['markDispatchesForwarded(): () => void']} />

Marks the emitter as forwarding its dispatches, until the returned function is called, so that listeners meant to
run on one process only (`RegisterAsDispatchListener`) stay idle on it. An emitter without it forwards without
telling.
