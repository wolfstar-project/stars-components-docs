The payload type of every event a [BrokerListener](/documentation/api/plugin-broker/namespaces/BrokerListener) can be registered for, keyed by event name.

<ApiSignature tokens={['interface BrokerEvents']} />

Empty by design: augment it in your application to type the events your bot publishes and consumes.

**Example**

```typescript
declare module '@wolfstar/plugin-broker' {
	interface BrokerEvents {
		messageCreate: GatewayMessageCreateDispatchData;
	}
}
```
