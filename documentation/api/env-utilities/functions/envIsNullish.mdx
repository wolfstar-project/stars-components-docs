Checks if the value of the specified environment variable is nullish.

## Parameters

### key

keyof [`Env`](../interfaces/Env)

## Returns

`boolean`

Whether the value of the specified environment variable is:
- `undefined`
- An empty string (`""`)
- The string `"0"`
- The string `"null"`, case insensitive
