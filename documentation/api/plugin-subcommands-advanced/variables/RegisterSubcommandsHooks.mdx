Optional hooks for parent commands that register chat-input commands imperatively
via [Command.registerApplicationCommands](/documentation/api/plugin-subcommands-advanced/classes/Command). Prefer relying on the automatic
wiring performed by [SubcommandsAdvancedLoaderStrategy](/documentation/api/plugin-subcommands-advanced/classes/SubcommandsAdvancedLoaderStrategy); these helpers are
useful when you want to inspect or manually attach builders during registration.
