Loader strategy that wires modular subcommands onto parent commands before
chat-input mappings are published to `CommandStore.router`.

[CommandStore.loadAll](/documentation/api/plugin-api/classes/MiddlewareStore) constructs every piece first, then inserts them. The
first [onLoad](/documentation/api/plugin-subcommands-advanced/classes/SubcommandsAdvancedLoaderStrategy#onload) resolves all deferred children, so every parent sees a complete
registry while builders avoid the construction phase.
