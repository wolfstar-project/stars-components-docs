### fetchLanguage

<ApiMember kind="property" signature={['fetchLanguage: (context: ', ['InternationalizationContext', '/documentation/api/plugin-i18next/interfaces/InternationalizationContext'], ') => Awaitable<string | null>']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/e92aba58265993929cc64df3a7c9948a05850e13/packages/plugin-i18next/src/lib/InternationalizationHandler.ts#L115', label: 'packages/plugin-i18next/src/lib/InternationalizationHandler.ts:115' }}>

The method to be overridden by the developer.

In the event that `fetchLanguage` is not defined or returns null / undefined, the interaction's
locales are used instead.

**Example 1**

```typescript
// Always use the same language (no per-guild configuration):
container.i18n.fetchLanguage = () => 'en-US';
```

**Example 2**

```typescript
// Retrieving the language from an ORM:
container.i18n.fetchLanguage = async (context) => {
	if (!context.guildId) return null;
	const guild = await driver.getRepository(GuildEntity).findOne({ id: context.guildId });
	return guild?.language ?? 'en-US';
};
```

</ApiMember>
