Resolves a key and its parameters using [fetchLanguage](/documentation/api/plugin-i18next/functions/fetchLanguage), meaning a custom
[InternationalizationHandler.fetchLanguage](/documentation/api/plugin-i18next/classes/InternationalizationHandler#fetchlanguage) hook (for example, a per-guild database lookup)
is honoured.

Use [getSupportedLanguageT](/documentation/api/plugin-i18next/functions/getSupportedLanguageT) when the language can be resolved from the target payload
alone, it is synchronous and does not hit the hook.
