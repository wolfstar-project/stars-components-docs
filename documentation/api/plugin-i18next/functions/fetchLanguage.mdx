Retrieves the language name for a target, using [InternationalizationHandler.fetchLanguage](/documentation/api/plugin-i18next/classes/InternationalizationHandler#fetchlanguage).

If that hook is not defined or returns a nullish value, the language is resolved from the
locales the target carries through [getSupportedLanguageName](/documentation/api/plugin-i18next/functions/getSupportedLanguageName), which itself falls back to
[InternationalizationOptions.defaultName](/documentation/api/plugin-i18next/interfaces/InternationalizationOptions#defaultname) and then to `'en-US'`.

This is the only helper that can resolve a language for a [ChannelTarget](/documentation/api/plugin-i18next/interfaces/ChannelTarget) or a
[MessageTarget](/documentation/api/plugin-i18next/interfaces/MessageTarget), since those payloads carry no locale and the hook receives their
`guildId` and `channelId`.
