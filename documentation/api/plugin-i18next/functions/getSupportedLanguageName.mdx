Resolves the loaded language that best matches the guild's locale, falling back to the user's one
when the target does not belong to a guild, then to
[InternationalizationOptions.defaultName](/documentation/api/plugin-i18next/interfaces/InternationalizationOptions#defaultname), and finally to `'en-US'`.

The guild locale comes from `guild_locale` on an [Interaction](/documentation/api/plugin-i18next/type-aliases/Interaction) and from `preferred_locale`
on a [GuildTarget](/documentation/api/plugin-i18next/interfaces/GuildTarget). A [ChannelTarget](/documentation/api/plugin-i18next/interfaces/ChannelTarget) and a [MessageTarget](/documentation/api/plugin-i18next/interfaces/MessageTarget) carry no locale, so
they resolve to the fallback unless a custom
[InternationalizationHandler.fetchLanguage](/documentation/api/plugin-i18next/classes/InternationalizationHandler#fetchlanguage) hook is used through [fetchLanguage](/documentation/api/plugin-i18next/functions/fetchLanguage).
