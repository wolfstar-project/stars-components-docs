Resolves the loaded language that best matches the user's locale, falling back to the guild's one,
then to [InternationalizationOptions.defaultName](/documentation/api/plugin-i18next/interfaces/InternationalizationOptions#defaultname), and finally to `'en-US'`.

Only an [Interaction](/documentation/api/plugin-i18next/type-aliases/Interaction) carries a user locale. For a [GuildTarget](/documentation/api/plugin-i18next/interfaces/GuildTarget) this is equivalent to
[getSupportedLanguageName](/documentation/api/plugin-i18next/functions/getSupportedLanguageName), and a [ChannelTarget](/documentation/api/plugin-i18next/interfaces/ChannelTarget) or [MessageTarget](/documentation/api/plugin-i18next/interfaces/MessageTarget) always
resolves to the fallback.
