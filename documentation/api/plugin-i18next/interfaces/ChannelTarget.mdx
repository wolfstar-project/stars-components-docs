The subset of a channel payload the localization helpers need. Every `APIChannel` member
satisfies it.

<ApiSignature tokens={['interface ChannelTarget']} />

A channel payload carries no locale of its own, so the language is resolved from
[InternationalizationHandler.fetchLanguage](/documentation/api/plugin-i18next/classes/InternationalizationHandler#fetchlanguage) and then from the configured default.
