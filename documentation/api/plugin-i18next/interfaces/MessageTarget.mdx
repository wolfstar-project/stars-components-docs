The subset of a message payload the localization helpers need. `APIMessage` satisfies it, and
gateway message payloads additionally carry `guild_id`.

<ApiSignature tokens={['interface MessageTarget']} />

Like [ChannelTarget](/documentation/api/plugin-i18next/interfaces/ChannelTarget), a message carries no locale of its own.
