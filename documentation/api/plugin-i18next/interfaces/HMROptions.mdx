Configure whether to use Hot-Module-Replacement (HMR) for your i18next resources using these
options. The minimum config to enable HMR is to set `enabled` to true. Any other properties are
optional.

<ApiSignature tokens={['interface HMROptions']} />

false;

### languages?

<ApiMember kind="property" badges={['optional']} signature={['languages?: string | string[]']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/e92aba58265993929cc64df3a7c9948a05850e13/packages/plugin-i18next/src/lib/types.ts#L149', label: 'packages/plugin-i18next/src/lib/types.ts:149' }}>

Languages that will be reloaded when updating the languages directory.

Pinning both this and [HMROptions.namespaces](/documentation/api/plugin-i18next/interfaces/HMROptions#namespaces) skips the directory walk, so languages and
namespaces added while the process is running are not registered on i18next.

**Default**

```ts
All languages that are automatically resolved from your folder setup
```

</ApiMember>

### namespaces?

<ApiMember kind="property" badges={['optional']} signature={['namespaces?: string | string[]']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/e92aba58265993929cc64df3a7c9948a05850e13/packages/plugin-i18next/src/lib/types.ts#L159', label: 'packages/plugin-i18next/src/lib/types.ts:159' }}>

Namespaces that will be reloaded when updating the languages directory.

Pinning both this and [HMROptions.languages](/documentation/api/plugin-i18next/interfaces/HMROptions#languages) skips the directory walk, so languages and
namespaces added while the process is running are not registered on i18next.

**Default**

```ts
All namespaces that are automatically resolved from your languages folder setup
```

</ApiMember>
