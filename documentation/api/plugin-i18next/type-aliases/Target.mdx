The four members are told apart structurally, in this order: an [Interaction](/documentation/api/plugin-i18next/type-aliases/Interaction) has `locale`,
a [MessageTarget](/documentation/api/plugin-i18next/interfaces/MessageTarget) has `channel_id`, a [ChannelTarget](/documentation/api/plugin-i18next/interfaces/ChannelTarget) has `type`, and anything else is
a [GuildTarget](/documentation/api/plugin-i18next/interfaces/GuildTarget).
