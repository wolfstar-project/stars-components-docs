Spawns every shard as a child process with `child_process.fork`. The default strategy.

<ApiSignature tokens={['class ForkStrategy extends ', ['ProcessStrategy', '/documentation/api/plugin-sharder/classes/ProcessStrategy']]} />

<ApiHierarchy extends={[[['ProcessStrategy', '/documentation/api/plugin-sharder/classes/ProcessStrategy']]]} />

Every shard is its own process: ports opened by the shards (e.g. an HTTP interactions server) must differ.
