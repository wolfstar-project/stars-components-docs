<ApiSignature
	tokens={['class ShardClient extends EventEmitter<', ['ShardClientEvents', '/documentation/api/plugin-sharder/interfaces/ShardClientEvents'], '>']}

<ApiHierarchy extends={[['EventEmitter<', ['ShardClientEvents', '/documentation/api/plugin-sharder/interfaces/ShardClientEvents'], '>']]} />

**Example**

```ts
const shard = new ShardClient();
const client = new GatewayClient({
  ...options,
  ...shard.gatewayOptions,
  gateway: { buildIdentifyThrottler: () => shard.identifyThrottler },
});
// Reuse the manager's `GET /gateway/bot` rather than requesting it again.
client.gateway.fetchGatewayInformation = () => shard.fetchGatewayInformation();
shard.setRequestHandler((body) => ...);
```

### addExitHook()

<ApiMember kind="method" source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-sharder/src/ShardClient.ts#L481', label: 'packages/plugin-sharder/src/ShardClient.ts:481' }}>

<ApiSignature tokens={['addExitHook(hook: ', ['ShardExitHook', '/documentation/api/plugin-sharder/type-aliases/ShardExitHook'], '): () => void']} />

Runs a hook before the shard stops: on [ShardClient.exit](/documentation/api/plugin-sharder/classes/ShardClient#exit), on [ShardClient.restart](/documentation/api/plugin-sharder/classes/ShardClient#restart), once the close
handler of a close from the manager resolved, and when the manager is gone and nothing listens to `disconnect`.
The place to flush what is left to export, such as traces: the shard stops with `process.exit`, which skips
`beforeExit`.

The hooks run one after the other, in the order they were added, before the shard tells the manager it stops. A
hook that throws is reported through the `error` event (or logged when nothing listens) and does not stop the
others, nor the shard. They run once: a path that stops the shard while they run (the manager going away during
`exit()`) waits for them. Adding the same function twice adds it once.
