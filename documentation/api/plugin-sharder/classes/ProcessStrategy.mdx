The base of [ForkStrategy](/documentation/api/plugin-sharder/classes/ForkStrategy) and [ClusterStrategy](/documentation/api/plugin-sharder/classes/ClusterStrategy): a shard is a process with an IPC channel, using the
`advanced` serialization so binary data (and [RawMessageHandler](/documentation/api/plugin-sharder/classes/RawMessageHandler)'s values) survive it.
