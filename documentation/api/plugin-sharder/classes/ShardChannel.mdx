The manager's channel to one shard: a process, cluster worker, worker thread, or remote process, connecting some
gateway shards.

<ApiSignature
	tokens={[
		'class ShardChannel extends EventEmitter<',
		['ShardChannelEvents', '/documentation/api/plugin-sharder/interfaces/ShardChannelEvents'],
		'>'
	]}
/>

<ApiHierarchy extends={[['EventEmitter<', ['ShardChannelEvents', '/documentation/api/plugin-sharder/interfaces/ShardChannelEvents'], '>']]} />

Named after discord.js's sharder: a "shard" is the client a manager spawns, and the channel is how the manager
talks to it, whatever the channel strategy.
