Answers the requests of the other side. Its return value (or the value it resolves to) is the reply, and a throw is
rejected on the other side as a [ShardRequestError](/documentation/api/plugin-sharder/classes/ShardRequestError). It may also return a `Result`: `Ok` is the reply, `Err`
the error.
