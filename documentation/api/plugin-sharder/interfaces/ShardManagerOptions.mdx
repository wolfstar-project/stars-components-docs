### shards?

<ApiMember kind="property" badges={['optional']} signature={['shards?: number | readonly number[] | "auto"']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/e92aba58265993929cc64df3a7c9948a05850e13/packages/plugin-sharder/src/ShardManager.ts#L60', label: 'packages/plugin-sharder/src/ShardManager.ts:60' }} inheritedFrom={[['ShardLayoutOptions.shards', '/documentation/api/plugin-sharder/interfaces/ShardLayoutOptions#shards']]}>

The layout: a number spawns one shard per gateway shard, an array spawns one shard per entry connecting that
many gateway shards, and `"auto"` splits the gateway shards across `clusters` shards.

**Default**

```ts
'auto';
```

**Example**

```ts
// 9 shards, connecting one gateway shard each.
new ShardManager({ shards: 9 });
// 3 shards, connecting 3 gateway shards each: 0-2, 3-5 and 6-8.
new ShardManager({ shards: [3, 3, 3] });
// Discord's recommended count, split across 4 shards.
new ShardManager({ shards: 'auto', clusters: 4 });
```

</ApiMember>
