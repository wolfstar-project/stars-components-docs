How a manager restarts crashing shards, after Erlang/OTP's supervisors: a shard crashing more than `intensity`
times within `period` is given up on.

<ApiSignature tokens={['interface SupervisorOptions']} />

## Properties

### intensity?

<ApiMember kind="property" badges={['optional']} signature={['intensity?: number']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-sharder/src/util/Supervisor.ts#L20', label: 'packages/plugin-sharder/src/util/Supervisor.ts:20' }}>

How many crashes are tolerated, `-1` or `Infinity` for no limit.

**Default**

```ts
-1;
```

</ApiMember>

### period?

<ApiMember kind="property" badges={['optional']} signature={['period?: number']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-sharder/src/util/Supervisor.ts#L27', label: 'packages/plugin-sharder/src/util/Supervisor.ts:27' }}>

The window the crashes are counted in, in milliseconds. `0` counts the crashes in a row instead, until the shard
is ready again.

**Default**

```ts
0;
```

</ApiMember>
