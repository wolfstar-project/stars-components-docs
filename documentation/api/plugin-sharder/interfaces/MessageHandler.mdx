The manager tells its shards the name of its handler, and [ShardClient](/documentation/api/plugin-sharder/classes/ShardClient) builds the same one from the registry
(see [registerMessageHandler](/documentation/api/plugin-sharder/functions/registerMessageHandler)): a custom handler must be registered in the shards too.
