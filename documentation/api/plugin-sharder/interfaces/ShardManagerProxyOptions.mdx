### localRouting?

<ApiMember kind="property" badges={['optional']} signature={['localRouting?: boolean']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-sharder/src/ShardManagerProxy.ts#L154', label: 'packages/plugin-sharder/src/ShardManagerProxy.ts:154' }}>

Whether to carry the messages and requests between shards of this proxy (and, with `peer`, of other proxies)
without going through the manager. It decodes their packets with the manager's message handler and
transformers, built from the registry: custom ones must be registered in the proxy too.

**Default**

```ts
true;
```

</ApiMember>

### managerLoss?

<ApiMember kind="property" badges={['optional']} signature={['managerLoss?: "exit" | "keep"']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-sharder/src/ShardManagerProxy.ts#L140', label: 'packages/plugin-sharder/src/ShardManagerProxy.ts:140' }}>

What the proxy does with the shards of a manager it loses: keep them running and reconnect (the manager takes
them back within its `reconnectGrace`), or stop them.

**Default**

```ts
'keep';
```

</ApiMember>

### managers

<ApiMember kind="property" signature={['managers: readonly (string | ', ['ProxyManagerAddress', '/documentation/api/plugin-sharder/interfaces/ProxyManagerAddress'], ')[]']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-sharder/src/ShardManagerProxy.ts#L94', label: 'packages/plugin-sharder/src/ShardManagerProxy.ts:94' }}>

The managers to connect to, as `{ host, port }` or `"host:port"`.

</ApiMember>

### mode?

<ApiMember kind="property" badges={['optional']} signature={['mode?: "all" | "failover"']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-sharder/src/ShardManagerProxy.ts#L103', label: 'packages/plugin-sharder/src/ShardManagerProxy.ts:103' }}>

How the proxy serves its managers:

- `"failover"`: one at a time, the first reachable, failing over to the next ones when it loses it.
- `"all"`: all of them at once, sharing its capacity, e.g. managers each running part of the gateway shards.

**Default**

```ts
'failover';
```

</ApiMember>

### name?

<ApiMember kind="property" badges={['optional']} signature={['name?: string']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-sharder/src/ShardManagerProxy.ts#L114', label: 'packages/plugin-sharder/src/ShardManagerProxy.ts:114' }}>

The name of the proxy, unique across the proxies of a manager. It finds its shards back under it after a
reconnection.

**Default:** `${os.hostname()}:${process.pid}`

</ApiMember>

<ApiMember kind="property" badges={['optional']} signature={['peer?: ', ['ProxyPeerOptions', '/documentation/api/plugin-sharder/interfaces/ProxyPeerOptions']]} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-sharder/src/ShardManagerProxy.ts#L159', label: 'packages/plugin-sharder/src/ShardManagerProxy.ts:159' }}>

Accepts connections from other proxies, and connects to them, to carry the messages between shards of different
proxies directly. Needs `localRouting`.

</ApiMember>
