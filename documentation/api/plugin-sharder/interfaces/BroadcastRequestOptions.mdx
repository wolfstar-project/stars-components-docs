## Properties

### partial?

<ApiMember kind="property" badges={['optional']} signature={['partial?: boolean']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/5bb3b6c632bbc7d73534213f6634e9fd02ee1c15/packages/plugin-sharder/src/util/requests.ts#L33', label: 'packages/plugin-sharder/src/util/requests.ts:33' }}>

Whether to resolve with the outcome of every shard, like `Promise.allSettled`, rather than rejecting on the first
failure: the replies that came before a timeout or an abort are kept.

</ApiMember>

### signal?

<ApiMember kind="property" badges={['optional']} signature={['signal?: AbortSignal']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/5bb3b6c632bbc7d73534213f6634e9fd02ee1c15/packages/plugin-sharder/src/util/requests.ts#L22', label: 'packages/plugin-sharder/src/util/requests.ts:22' }} inheritedFrom={[['RequestOptions.signal', '/documentation/api/plugin-sharder/interfaces/RequestOptions#signal']]}>

Aborts the request: dropped from the queue if it waits for a shard to be ready, and aborted on the other side
otherwise, whose handler gets an aborted `signal`.

</ApiMember>
