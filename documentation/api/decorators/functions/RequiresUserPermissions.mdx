> **RequiresUserPermissions**(...`permissions`): `MethodDecorator`

Defined in: [packages/decorators/src/RequiresPermissions.ts:94](https://github.com/wolfstar-project/stars-components/blob/3aa572c78006b3dffdba8ff804c781498fef6153/packages/decorators/src/RequiresPermissions.ts#L94)

Decorator that only runs the decorated method when the invoking user has all of the given permissions in the channel
the interaction was sent from.

## Parameters

### permissions

...`PermissionResolvable`[]

The permissions the invoking user must have.

## Returns

`MethodDecorator`

A method decorator.

## Remarks

Interactions received outside of a guild carry no member permissions, so the check passes for them. Pair
this decorator with [`RequiresGuildContext`](/documentation/api/decorators/functions/RequiresGuildContext) when the method must also be guild-only.

## Example

```typescript
import { RequiresUserPermissions } from '@wolfstar/decorators';
import { Command, RegisterCommand } from '@wolfstar/http-framework';

(at)RegisterCommand({ name: 'ban', description: 'Bans a member' })
export class UserCommand extends Command {
	(at)RequiresUserPermissions('BanMembers')
	public override chatInputRun(interaction: Command.ChatInputInteraction) {
		return interaction.reply({ content: 'Banned!' });
	}
}
```
