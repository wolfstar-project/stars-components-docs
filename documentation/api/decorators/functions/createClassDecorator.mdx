Utility to make a class decorator from a function.

## Type Parameters

### TFunction

`TFunction` _extends_ (...`args`) => `unknown`

## Parameters

### fn

`TFunction`

The class to decorate.

## Returns

`TFunction`

The decorator.

## Remarks

The decorator is returned with the signature it was given, rather than widened to `ClassDecorator`, so a
decorator built on top of this keeps whatever constraint it declares on its target, such as only accepting a
`Command` subclass.
