> **EnumerableMethod**(`value`): (`_target`, `_key`, `descriptor`) => `void`

Defined in: [packages/decorators/src/Enumerable.ts:59](https://github.com/wolfstar-project/stars-components/blob/3aa572c78006b3dffdba8ff804c781498fef6153/packages/decorators/src/Enumerable.ts#L59)

Decorator that sets the `enumerable` property of a class method to the given value.

## Parameters

### value

`boolean`

Whether the method should be enumerable or not.

## Returns

A method decorator.

(`_target`, `_key`, `descriptor`) => `void`

## Example

```typescript
import { EnumerableMethod } from '@wolfstar/decorators';
import { Command } from '@wolfstar/http-framework';

export class UserCommand extends Command {
	(at)EnumerableMethod(true)
	public getCacheKey(id: string) {
		return `user:${id}`;
	}
}
```
