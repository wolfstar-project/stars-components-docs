### ready?

<ApiMember kind="property" badges={['optional']} signature={['ready?: () => boolean | ', ['PromiseLike', 'https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise'], '<boolean | void>']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/5bb3b6c632bbc7d73534213f6634e9fd02ee1c15/packages/plugin-scheduled-tasks/src/lib/types/ScheduledTaskTypes.ts#L29', label: 'packages/plugin-scheduled-tasks/src/lib/types/ScheduledTaskTypes.ts:29' }}>

Whether the app is ready to run the tasks that set the `waitForReady` task option: `true` or a promise
that resolves (to anything but `false`) means it is. A job waits for it before its task runs.

A function cannot be written in `stars.config`, so this is for `scheduledTasks()` and `ClientOptions.tasks`.

**Example**

```ts
scheduledTasks({ ready: () => container.gatewayClient.isClientReady() });
```

</ApiMember>

### readyTimeout?

<ApiMember kind="property" badges={['optional']} signature={['readyTimeout?: number']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/5bb3b6c632bbc7d73534213f6634e9fd02ee1c15/packages/plugin-scheduled-tasks/src/lib/types/ScheduledTaskTypes.ts#L38', label: 'packages/plugin-scheduled-tasks/src/lib/types/ScheduledTaskTypes.ts:38' }}>

How long (in milliseconds) a job waits for [ScheduledTaskHandlerOptions.ready](/documentation/api/plugin-scheduled-tasks/interfaces/ScheduledTaskHandlerOptions#ready) before it is delayed.

The worker runs one job at a time, so a waiting job holds back the others for up to this long.

**Default**

```ts
30_000;
```

</ApiMember>
