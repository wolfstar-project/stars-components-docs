### run()

<ApiMember kind="method" source={{ url: 'https://github.com/wolfstar-project/plugins/blob/e92aba58265993929cc64df3a7c9948a05850e13/packages/plugin-scheduled-tasks/src/lib/ScheduledTaskHandler.ts#L273', label: 'packages/plugin-scheduled-tasks/src/lib/ScheduledTaskHandler.ts:273' }}>

<ApiSignature
	tokens={[
		'run(\n  task: ',
		['ScheduledTasksResolvable', '/documentation/api/plugin-scheduled-tasks/type-aliases/ScheduledTasksResolvable'],
		',\n  context: ',
		['ScheduledTaskRunContext', '/documentation/api/plugin-scheduled-tasks/interfaces/ScheduledTaskRunContext'],
		' = {}\n): ',
		['Promise', 'https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise'],
		'<number | undefined>'
	]}
/>

Runs a scheduled task with the given name and payload.

- `undefined` will be returned if the task was not found, or if it waits for the app to be ready, which it was
  not after the timeout, and there is no job to delay.
- With a job, a task that was not ready in time moves its job to `delayed` and throws BullMQ's `DelayedError`,
  which the worker takes as "leave the job alone": it costs no attempt and is not a task error.

<ApiParams title="Parameters">

<ApiParam name="task" type={[['ScheduledTasksResolvable', '/documentation/api/plugin-scheduled-tasks/type-aliases/ScheduledTasksResolvable']]}>

The name of the scheduled task to run.

</ApiParam>

<ApiParam name="context" type={[['ScheduledTaskRunContext', '/documentation/api/plugin-scheduled-tasks/interfaces/ScheduledTaskRunContext']]} defaultValue={'{}'}>

The job being processed, which lets a task that waits for the app to be ready be delayed.

</ApiParam>

</ApiParams>

<ApiParams title="Returns">

<ApiParam type={[['Promise', 'https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise'], '<number | undefined>']}>

The duration of the run in milliseconds.

</ApiParam>

</ApiParams>

</ApiMember>

<ApiMember kind="method" source={{ url: 'https://github.com/wolfstar-project/plugins/blob/e92aba58265993929cc64df3a7c9948a05850e13/packages/plugin-scheduled-tasks/src/lib/ScheduledTaskHandler.ts#L242', label: 'packages/plugin-scheduled-tasks/src/lib/ScheduledTaskHandler.ts:242' }}>

Waits for the app to be ready, as defined by the `ready` option.

A `ready` that returns `false` is polled until the timeout, and a promise is waited for until it. If `ready`
throws or rejects, so does this.

<ApiParams title="Parameters">

</ApiParams>

<ApiParams title="Returns">
