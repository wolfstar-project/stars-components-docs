### expiredReply?

<ApiMember kind="property" badges={['optional']} signature={['expiredReply?: string']} source={{ url: 'https://github.com/wolfstar-project/stars-components/blob/c2542d72639334a6f68ac733336ee9e95abf4d15/packages/http-framework-utilities/src/lib/PaginatedMessage/PaginatedMessage.ts#L69', label: 'packages/http-framework-utilities/src/lib/PaginatedMessage/PaginatedMessage.ts:69' }}>

The ephemeral notice sent when a click cannot be handled while its session is still readable, e.g. a custom
action or a lazy page that is only available on the process that started the message. A session that expired or
is unknown cannot be read, so its clicks get the process-wide notice set with `setDefaultExpiredReply` instead.

**Default**

```ts
getDefaultExpiredReply();
```

</ApiMember>
