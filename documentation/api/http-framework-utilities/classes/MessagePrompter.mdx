Sends the question with its buttons as a bot-owned, non-ephemeral message through `send` (e.g. a gateway reply or
a channel message) and waits for the answer. Its timeout cleanup edits the returned message through the bot's REST
route, so the timeout is not bound by [`MaximumTokenLifetime`](/documentation/api/http-framework-utilities/variables/MaximumTokenLifetime).

<ApiParams title="Parameters">

<ApiParam name="ownerId" type={['string']}>

The user allowed to answer.

</ApiParam>

<ApiParam name="send" type={['(payload: ', ['APIInteractionResponseCallbackData', 'https://discord-api-types.dev/api/discord-api-types-v10#APIInteractionResponseCallbackData'], ') => ', ['Promise', 'https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise'], '<{\n  channelId: string;\n  messageId: string;\n}>']}>

Sends the payload and resolves with the created message's id and channel id.

</ApiParam>

</ApiParams>
