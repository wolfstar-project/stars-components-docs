Translates a gateway dispatch into the list of [CacheOperation](/documentation/api/plugin-cache/type-aliases/CacheOperation)s it implies, including the cascades (e.g.
`CHANNEL_DELETE` also drops that channel's messages).

This is a pure function, it does not touch any cache. Use [applyGatewayDispatch](/documentation/api/plugin-cache/functions/applyGatewayDispatch) to apply them.
`INTERACTION_CREATE` is intentionally ignored: interactions are short-lived and never cached.
