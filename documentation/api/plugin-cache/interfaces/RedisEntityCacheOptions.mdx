## Properties

### codec?

<ApiMember kind="property" badges={['optional']} signature={['codec?: ', ['CacheCodec', '/documentation/api/plugin-cache/interfaces/CacheCodec']]} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-cache/src/lib/redis.ts#L131', label: 'packages/plugin-cache/src/lib/redis.ts:131' }}>

The codec used to encode and decode values.

Values are tagged with [CacheCodec.name](/documentation/api/plugin-cache/interfaces/CacheCodec#name), so changing the codec never breaks reading entries written
under the default `jsonCodec()`: untagged entries are decoded with it, regardless of what `codec` is now set to.
Switching _away_ from a previously configured non-default codec instead requires listing it in
[RedisEntityCacheOptions.legacyCodecs](/documentation/api/plugin-cache/interfaces/RedisEntityCacheOptions#legacycodecs), since nothing else records which codec wrote which entry.

**Default**

```ts
jsonCodec();
```

</ApiMember>

### guildOf?

<ApiMember kind="property" badges={['optional']} signature={['guildOf?: (key: string, value?: Raw) => string | undefined']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-cache/src/lib/redis.ts#L119', label: 'packages/plugin-cache/src/lib/redis.ts:119' }}>

Resolves the guild an entry belongs to, indexing the entries by guild so [RedisEntityCache.deleteGuild](/documentation/api/plugin-cache/classes/RedisEntityCache#deleteguild)
does not have to scan the whole cache. Entries it resolves no guild for are not indexed. Without it, nothing is
indexed and `deleteGuild` resolves to `null`.

On delete, it is first called without the value: when the key alone gives the guild away, the value is not
read back.

</ApiMember>

### legacyCodecs?

<ApiMember kind="property" badges={['optional']} signature={['legacyCodecs?: readonly ', ['CacheCodec', '/documentation/api/plugin-cache/interfaces/CacheCodec'], '[]']} source={{ url: 'https://github.com/wolfstar-project/plugins/blob/775d46b1424d1408340cd641b136e181dbcf011c/packages/plugin-cache/src/lib/redis.ts#L140', label: 'packages/plugin-cache/src/lib/redis.ts:140' }}>

Former [RedisEntityCacheOptions.codec](/documentation/api/plugin-cache/interfaces/RedisEntityCacheOptions#codec) values this cache's entries may still be tagged with, tried in
order (after the current `codec`) before falling back to `jsonCodec()`. Required to keep reading entries
written under a codec you are migrating away from.

Only used for decoding: entries are always written with the current `codec`.

</ApiMember>
