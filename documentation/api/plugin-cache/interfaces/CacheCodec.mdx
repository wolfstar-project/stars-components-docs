Encodes and decodes cached values to and from their stored representation.

<ApiSignature tokens={['interface CacheCodec']} />

`name` is stored alongside every encoded value (see [RedisEntityCache](/documentation/api/plugin-cache/classes/RedisEntityCache)), so switching a cache's codec never
breaks reading entries written under a previous one.
