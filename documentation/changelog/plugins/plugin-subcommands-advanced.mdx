Changes to [`@wolfstar/plugin-subcommands-advanced`](https://github.com/wolfstar-project/plugins/tree/main/packages/plugin-subcommands-advanced). The plugin lets you build modular slash subcommands as separate command classes for `@wolfstar/http-framework`. For the weekly summary across all packages, see the [changelog overview](/documentation/changelog/index).

## `2.1.0`

### New features

- **Module and plugin entrypoints** — Add `@wolfstar/plugin-subcommands-advanced/module` and `@wolfstar/plugin-subcommands-advanced/plugin`. List the module in `modules` in `stars.config`, or pass the `definePlugin` factory to `plugins`. Both need framework 6.1 (and `@wolfstar/kit` for the module). `./register` is unchanged and still supports framework v3, v5, and v6. ([#193](https://github.com/wolfstar-project/plugins/pull/193))

## `2.0.6`

### Bug fixes

- **Peer range** — Accept `@wolfstar/http-framework` v6 in the peer range (`|| ^6.0.0`). ([#176](https://github.com/wolfstar-project/plugins/pull/176))

## `2.0.5`

### Bug fixes

- **Peer dependency** — Accept `@wolfstar/http-framework` v5 as a peer dependency (`^3.1.0 || ^5.0.0`), so v5 projects no longer install the plugin with an unmet peer. ([#125](https://github.com/wolfstar-project/plugins/pull/125))

## `2.0.4` (2026-09-17)

### Bug fixes

- **Deferred builder callbacks** — Subcommand builder callbacks are now deferred until every command piece has been constructed, fixing crashes when builders referenced not-yet-loaded siblings. ([#83](https://github.com/wolfstar-project/plugins/pull/83))
- **Dependencies** — Updated all non-major dependencies. ([#75](https://github.com/wolfstar-project/plugins/pull/75))

## `2.0.3`

### Updates

- **Type validation** — Validate every published subpath export with `are-the-types-wrong`, not just the main entrypoint. `createTsdownOptions` hardcoded `attw.entrypoints` to `["."]`, so the `./register` export of each package shipped unchecked. It now accepts an `attwEntrypoints` option, and all packages list their real entrypoints. ([#70](https://github.com/wolfstar-project/plugins/pull/70))

## `2.0.2`

### Updates

- **Dependencies** — Updated all non-major dependencies. ([#47](https://github.com/wolfstar-project/plugins/pull/47))

## `2.0.1`

### Updates

- **Dependencies** — Updated all non-major dependencies. ([#26](https://github.com/wolfstar-project/plugins/pull/26))

### Bug fixes

- **Registry registration** — Fix `RegisterAsSubcommand` and `RegisterAsSubcommandGroup` not registering the decorated subcommand piece in `applicationCommandRegistry`, which prevented modular subcommand classes from being recognized as application commands. ([#30](https://github.com/wolfstar-project/plugins/pull/30))

## `2.0.0`

### New features

- **New package** — Add `@wolfstar/plugin-subcommands-advanced`: modular slash subcommands as separate command classes for `@wolfstar/http-framework`, adapted from `@kaname-png/plugin-subcommands-advanced`. ([#17](https://github.com/wolfstar-project/plugins/pull/17))

## `1.0.0`

### New features

- **Initial release** — Modular slash subcommands as separate command classes for `@wolfstar/http-framework`.
