Changes to [`@wolfstar/plugin-api`](https://github.com/wolfstar-project/plugins/tree/main/packages/plugin-api). The plugin adds a standalone REST API server to your Stars bot, with routes, middleware, and a router. For the weekly summary across all packages, see the [changelog overview](/documentation/changelog/index).

## `2.1.0`

### New features

- **Module and plugin entrypoints** — Add `@wolfstar/plugin-api/module` and `@wolfstar/plugin-api/plugin`. List the module in `modules` in `stars.config`, or pass the `definePlugin` factory to `plugins`. Both need framework 6.1 (and `@wolfstar/kit` for the module). `./register` is unchanged and still supports framework v3, v5, and v6. ([#194](https://github.com/wolfstar-project/plugins/pull/194))

## `2.0.0` (2026-10-01)

### New features

- **Sapphire 8.3.1 parity** — The plugin now matches `@sapphire/plugin-api` 8.3.1, except for authentication. Added: `CookieStore` and the `cookies` middleware, body readers (`readBody*`, `readValidatedBody*`, `asWeb`), the full `ApiResponse` helper set, `ServerOptions.prefix`, per-route `maximumBodyLength`, the `MiddlewareSuccess`/`MiddlewareFailure` events, full router (`RouterBranch`/`RouterNode`) parity, `HttpCodes`, and a `version` export. ([#161](https://github.com/wolfstar-project/plugins/pull/161))

### Updates

- **Renames** — `ApiServer` is renamed `Server`, `ApiServerOptions`/`ApiServerEvents`/`ApiServerEvent` are `ServerOptions`/`ServerEvents`/`ServerEvent`, `ApiPlugin` is `Api`, and `HttpMethod` is `MethodName`.
- **Response helpers** — Use `response.status(code).json(data)` instead of `json(data, code)`.
- **Body reading** — `readBodyJson()` returns `unknown` and takes its limit from `maximumBodyLength`.
- **Query object** — `request.query` is a plain record.
- **Route matching** — A route with no methods now answers `404` instead of defaulting to `GET`, and `OPTIONS` answers `200` with an empty body instead of `204`.
- **Listener pieces** — Listener piece names are PascalCase.
- **Node version** — Requires Node.js `>=20.18.1`.

### Bug fixes

- Router path, route removal, and `supportedMethods` bugs inherited from upstream are fixed.
- `Server#connect()` now rejects instead of throwing uncaught when the port is in use.
- Malformed `Cookie` headers no longer crash parsing.

### Migration

- Replace `ApiServer` with `Server`, `ApiServerOptions` with `ServerOptions`, `ApiServerEvents` with `ServerEvents`, `ApiServerEvent` with `ServerEvent`, `ApiPlugin` with `Api`, and `HttpMethod` with `MethodName`.
- Replace `json(data, code)` with `status(code).json(data)`.
- Replace `readBodyJson<Shape>` with `readBodyJson()` returning `unknown`.
- Ensure Node.js is `>=20.18.1`.
