## `2.1.0`

### New features

- **Default Stars banner** — `createStarsBanner()` prints a compact banner with a small built-in Stars logo. Pass a custom `logo` array to replace it, or `logo: false` for text-only output. New scaffolded projects and the examples use this helper instead of embedding the artwork in every entry file. [#167](https://github.com/wolfstar-project/stars-components/pull/167)
