## `2.1.0`

### New features

- **`createStarsBanner()`** — Added a compact, replaceable default Stars banner. `createStarsBanner()` uses a small built-in Stars logo, accepts a custom `logo` array as a replacement, and supports `logo: false` for text-only output. Newly scaffolded projects and the runnable examples use this helper instead of embedding the default artwork in every entry file. ([#167](https://github.com/wolfstar-project/stars-components/pull/167))

## `2.0.9`

### Updates

- **Type checker** — Replaced `tsc` with `golar` as the type checker and bumped TypeScript to `7.0.2`. `typecheck` scripts now run `golar tsc` instead of `tsc` directly. This is a dev-tooling-only change with no effect on published output. ([#151](https://github.com/wolfstar-project/stars-components/pull/151))
