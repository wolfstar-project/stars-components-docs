Changes to [`@wolfstar/safe-fetch`](https://github.com/wolfstar-project/stars-components/tree/main/packages/safe-fetch). The package provides type-safe fetch wrappers with structured error handling. For the weekly summary across all packages, see the [changelog overview](/documentation/changelog/index).

## `1.1.10`

### Updates

- **Dependencies** — Updated all non-major dependencies. ([#178](https://github.com/wolfstar-project/stars-components/pull/178))

## `1.1.9`

### Updates

- **Type checker** — Replaced `tsc` with `golar` as the type checker and bumped TypeScript to `7.0.2`. `typecheck` scripts now run `golar tsc` instead of `tsc` directly. This is a dev-tooling-only change with no effect on published output. ([#151](https://github.com/wolfstar-project/stars-components/pull/151))

## `1.1.8`

### Updates

- **Provenance attestation** — Restored npm provenance attestation on publish for all packages. ([#107](https://github.com/wolfstar-project/stars-components/pull/107))

## `1.1.7`

### Updates

- **Build tooling** — Upgraded `tsdown` to `0.22.14` and migrated `deps.skipNodeModulesBundle` to `deps.neverBundle`. ([#93](https://github.com/wolfstar-project/stars-components/pull/93))

## `1.1.6`

### Updates

- **Provenance attestation** — Added provenance attestation to `publishConfig` for all packages. ([#59](https://github.com/wolfstar-project/stars-components/pull/59))
