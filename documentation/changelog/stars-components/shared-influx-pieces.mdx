This package provides shared influx pieces for Star Network's HTTP-only bots. For the weekly summary across all packages, see the [changelog overview](/documentation/changelog/index).

### Updates

- **Dependencies** — Updated `@wolfstar/env-utilities` to `2.1.1`, `@wolfstar/http-framework` to `4.0.1`, and `@wolfstar/influx-utilities` to `1.1.6`. ([#178](https://github.com/wolfstar-project/stars-components/pull/178))

### Updates

- **Dependencies** — Updated `@wolfstar/env-utilities` to `2.0.8`, `@wolfstar/http-framework` to `3.2.1`, and `@wolfstar/influx-utilities` to `1.1.5`.
