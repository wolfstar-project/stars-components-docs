## `2.0.11` (2026-10-08)

### Updates

- **Dependencies** — Updated `@wolfstar/http-framework` to `6.3.0`.

### Bug fixes

- **Sentry reporting** — The `error` listener no longer reports a `UserError` to Sentry. With `@wolfstar/http-framework` 6.3.0, a `UserError` is emitted as a `*Denied` event and no longer reaches the `commandError`, `autocompleteError`, or `interactionHandlerError` listeners. ([#298](https://github.com/wolfstar-project/stars-components/pull/298))
