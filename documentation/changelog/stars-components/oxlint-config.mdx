## `0.2.0` (2026-09-24)

### Updates

- **TypeScript config** — The package now default-exports a `defineConfig` object to pass to `extends` in `oxlint.config.ts`. The `.oxlintrc.json` entry point is removed. ([#202](https://github.com/wolfstar-project/stars-components/pull/202))

### Migration

Replace `import config from '@wolfstar/oxlint-config/.oxlintrc.json'` with `import config from '@wolfstar/oxlint-config'` and pass the default export to `extends` in `oxlint.config.ts`.

### New features

([#160](https://github.com/wolfstar-project/stars-components/pull/160))
