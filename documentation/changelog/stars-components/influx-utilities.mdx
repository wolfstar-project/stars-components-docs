Changes to [`@wolfstar/influx-utilities`](https://github.com/wolfstar-project/stars-components/tree/main/packages/influx-utilities). This package is a tiny opinionated abstraction layer for InfluxDB for interacting with a single organization. For the weekly summary across all packages, see the [changelog overview](/documentation/changelog/index).

## `1.1.6`

### Updates

- **Dependencies** — Updated all non-major dependencies. ([#178](https://github.com/wolfstar-project/stars-components/pull/178))
- **Dependencies** — Updated `@wolfstar/env-utilities` to `2.1.1`.

## `1.1.5`

### Updates

- **Build tooling** — Replaced `tsc` with `golar` as typechecker and bumped TypeScript to `7.0.2`. `typecheck` scripts now run `golar tsc` instead of `tsc` directly. This is a dev-tooling-only change with no effect on published output. ([#151](https://github.com/wolfstar-project/stars-components/pull/151))
- **Dependencies** — Updated `@wolfstar/env-utilities` to `2.0.8`.

## `1.1.4`

### Updates

- **Dependencies** — Updated `@wolfstar/env-utilities` to `2.0.5`.
