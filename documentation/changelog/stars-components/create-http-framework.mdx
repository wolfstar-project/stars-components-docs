Changes to [`@wolfstar/create-http-framework`](/documentation/packages/create-http-framework). For the weekly summary across all packages, see the [changelog overview](/documentation/changelog/index).

## `2.9.0` (2026-10-06)

### New features

- **Solution-style tsconfig for compatibility version 6** — `tsdown`, `vite` and `vite-nitro` projects get a root `tsconfig.json` of `{ "files": [], "references": [...] }` pointing at the `.stars/tsconfig.app.json` and `.stars/tsconfig.node.json` that `stars prepare` writes, plus a `typecheck` script that runs `stars typecheck`. The manifest records the `compatibilityVersion` the project was generated for, and the generated `AGENTS.md` and `README.md` document the script. The `tsc` template is unchanged. [#284](https://github.com/wolfstar-project/stars-components/pull/284)

### Updates

- **Safe reruns** — A rerun replaces the root `tsconfig.json` only if it's unchanged from what the generator wrote (this version's or the old `extends` one, ignoring formatting). A hand-edited file is kept, with a warning.

## `2.8.1` (2026-10-06)

### Updates

- **Dependencies** — Updated third-party dependencies.

## `2.8.0` (2026-10-04)

### New features

- **`AGENTS.md` and `llms.txt`** — Every project gets an `AGENTS.md` (commands, layout and easy-to-miss rules) and an `llms.txt` (upstream documentation by topic), both covering only the features you selected. [#258](https://github.com/wolfstar-project/stars-components/pull/258)
- **Framework lint rules** — With a linter selected, the generated `.oxlintrc.json` or `eslint.config.mjs` enables the rules of `@wolfstar/eslint-plugin-http-framework`.
- **Dev tunnel** — `--tunnel`, or the **Dev tunnel** feature in the prompt, writes `dev: { tunnel: true }` to `stars.config` so `stars dev` opens a cloudflared quick tunnel.

## 2026-09-24

### Updates

- **Schema split** — Scaffolded projects are unaffected by the move of the config schema to [`@wolfstar/schema`](/documentation/changelog/stars-components/schema).

## 2026-09-17

### New features

- **Generated TypeScript alias config** — Scaffolded projects extend the `.stars/tsconfig.json` that `stars prepare`, `stars dev`, and `stars build` write, and pick up Sapphire base, extra-strict, and decorators options automatically.
