## `3.1.0`

### New features

- **i18next v25 native TypeScript types** — `@wolfstar/http-framework-i18n` now targets i18next v25 with namespace-aware `getT` and `getSupportedLanguageT` helpers and drops the deprecated `T`, `FT`, `resolveKey`, and `resolveUserKey` APIs. `@wolfstar/shared-http-pieces` removes the hand-maintained `LanguageKeys` export in favour of the generated `CustomTypeOptions` augmentation and direct `TFunction<'commands/shared'>` usage. `@wolfstar/i18next-type-generator` is the CLI used to generate that augmentation from locale JSON files ([#30](https://github.com/wolfstar-project/stars-components/pull/30)).

### Updates

- **Typechecker** — Replaced `tsc` with `golar tsc` in the `typecheck` script. This is a dev-tooling-only change with no effect on published output. Also bumped TypeScript to `7.0.2` ([#151](https://github.com/wolfstar-project/stars-components/pull/151)).
