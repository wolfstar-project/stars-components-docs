## `3.1.0`

### New features

- **i18next v25 type generation** — Generate the `CustomTypeOptions` augmentation for i18next v25's native TypeScript types from your locale JSON files. `@wolfstar/shared-http-pieces` uses this augmentation in place of its removed `LanguageKeys` export. [#30](https://github.com/wolfstar-project/stars-components/pull/30)

### Updates

- **Typechecker** — Replaced `tsc` with `golar tsc` in the `typecheck` script. This is a dev-tooling-only change with no effect on published output. Also bumped TypeScript to `7.0.2` ([#151](https://github.com/wolfstar-project/stars-components/pull/151)).
