## `0.1.0`

### New features

- **Initial release** — Added shareable `oxlint`/`oxfmt`/`eslint`/`prettier` configs and a custom Wolfstar lint rules plugin. `@wolfstar/eslint-config` translates the repo's `oxlint`/`oxfmt` rules to an ESLint flat config for consumers who use ESLint instead. The bundled [`@wolfstar/eslint-plugin-http-framework`](/documentation/changelog/stars-components/eslint-plugin-http-framework) is an ESLint-compatible custom rules plugin that catches `@wolfstar/http-framework` decorator misuse and `@wolfstar/plugin-*` i18n pitfalls that TypeScript cannot catch on its own. ([#160](https://github.com/wolfstar-project/stars-components/pull/160))

### Updates

- **Dependencies** — Updated `@wolfstar/eslint-plugin-http-framework` to `0.1.0`.
