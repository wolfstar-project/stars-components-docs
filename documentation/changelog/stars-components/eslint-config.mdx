Changes to [`@wolfstar/eslint-config`](https://github.com/wolfstar-project/stars-components/tree/main/packages/eslint-config). The package is the [`@wolfstar/oxlint-config`](/documentation/changelog/stars-components/oxlint-config) rule set translated to ESLint flat config, for projects that use ESLint and Prettier instead of oxlint and oxfmt. For the weekly summary across all packages, see the [changelog overview](/documentation/changelog/index).

## `0.1.0`

### New features

- **Initial release** — A shareable ESLint flat config with the same rules as `@wolfstar/oxlint-config`. It bundles [`@wolfstar/eslint-plugin-http-framework`](/documentation/changelog/stars-components/eslint-plugin-http-framework) to catch `@wolfstar/http-framework` decorator misuse and `@wolfstar/plugin-*` i18n pitfalls that TypeScript can't catch. [#160](https://github.com/wolfstar-project/stars-components/pull/160)

### Updates
