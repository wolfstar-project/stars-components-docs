## `4.0.0`

### Updates

- **Vitest 5** — `vitest >=5.0.0` is now the optional peer dependency, and the `Assertion` augmentation in `@wolfstar/http-framework-test-utils/vitest` matches Vitest 5's `Assertion<R, T>` type parameters. ([#179](https://github.com/wolfstar-project/stars-components/pull/179))

### Migration

- **Upgrade Vitest** — Upgrade your project to `vitest` 5.0.0 or later before updating to this version.
- Update your `vitest` dependency to `>=5.0.0` to keep the `Assertion` augmentation compatible.
