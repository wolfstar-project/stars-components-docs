Changes to [`@wolfstar/eslint-plugin-http-framework`](https://github.com/wolfstar-project/stars-components/tree/main/packages/eslint-plugin-http-framework). The plugin catches misuse of `@wolfstar/http-framework` decorators and `@wolfstar/plugin-*` packages, and works with both ESLint and oxlint's JS plugin API.
