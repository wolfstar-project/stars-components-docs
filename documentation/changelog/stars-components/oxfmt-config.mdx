## `0.2.0` (2026-09-24)

### Updates

- **TypeScript config** — The package now default-exports a `defineConfig` object to spread into `oxfmt.config.ts`. The `index.json` entry point is removed. ([#202](https://github.com/wolfstar-project/stars-components/pull/202))

### Migration

Replace `import config from '@wolfstar/oxfmt-config/index.json'` with `import config from '@wolfstar/oxfmt-config'` and spread the default export into `oxfmt.config.ts`.

## `0.1.0`

### New features

- **Initial release** — Added shareable `oxlint`/`oxfmt`/`eslint`/`prettier` configs and a custom Wolfstar lint rules plugin. `@wolfstar/oxfmt-config` publishes the repo's `oxfmt` rules as a reusable base config for other `@wolfstar/*` projects. ([#160](https://github.com/wolfstar-project/stars-components/pull/160))
